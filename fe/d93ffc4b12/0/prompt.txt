### 3. SCHEMA QUERIES (Strategic Questions)

**Query 1: Papers Influencing Agent Decisions**
```sql
-- "Which papers influenced this agent's decisions?"
SELECT 
  agent_decision.*,
  ->APPLIED_RESEARCH->paper.title,
  ->APPLIED_RESEARCH.relevance_score
FROM agent_decision
WHERE session_id = $session_id
  AND ->APPLIED_RESEARCH EXISTS
ORDER BY ->APPLIED_RESEARCH.relevance_score DESC;
```

**Query 2: Lessons Validated by Agent Work**
```sql
-- "What lessons come from this agent's work?"
SELECT 
  agent_outcome.lessons_learned,
  ->VALIDATES_LESSON->lesson.{title, severity},
  ->VALIDATES_LESSON.alignment_score
FROM agent_outcome
WHERE session_id = $session_id
ORDER BY ->VALIDATES_LESSON.alignment_score DESC;
```

**Query 3: Misalignment Detection**
```sql
-- "Where is agent reasoning misaligned with research?"
SELECT 
  agent_reasoning.*,
  ->CHALLENGES_LESSON->lesson.{title, primary_source},
  agent_reasoning.source_notes
FROM agent_reasoning
WHERE decision_id->session_id = $session_id
  AND ->CHALLENGES_LESSON.challenge_type = "contradicts"
ORDER BY ->CHALLENGES_LESSON.challenge_type;
```

**Query 4: Decision Cascade Analysis**
```sql
-- "How did prior decisions cascade through the session?"
SELECT 
  agent_decision.*,

FROM agent_decision
WHERE session_id = $session_id
ORDER BY timestamp ASC;
```

### 7. IMPLEMENTATION PATTERN

**MCP Tool Example**:
```python
@mcp.tool()
def record_agent_decision(
    session_id: str,
    decision_type: str,  # "architecture", "feature", etc.
    reasoning: str,      # Chain of thought
    papers_applied: list[str],  # Paper IDs that informed this
    confidence_score: float
) -> str:
    """Record architectural decision with research lineage.
    
    Creates:
    - agent_decision node
    - agent_reasoning node
    - APPLIED_RESEARCH edges to cited papers
    
    Returns: decision_id for later validation
    """
    db = Surreal()
    decision_id = f"decision:{uuid.uuid4()}"
    
    # Create decision node
    db.create(f"agent_decision:{decision_id}", {
        "session_id": session_id,
        "decision_type": decision_type,
        "timestamp": datetime.now().isoformat(),
        "reasoning": reasoning,
        "confidence_score": confidence_score,
        "validation_status": "pending"
    })
    
    # Create reasoning node
    db.create(f"agent_reasoning:{uuid.uuid4()}", {
        "decision_id": decision_id,
        "reasoning_type": "research_based",
        "chain_of_thought": reasoning,
        "source_notes": papers_applied
    })
    
    # Link to papers
    for paper_id in papers_applied:
        db.relate(f"agent_decision:{decision_id}", "APPLIED_RESEARCH", 
                 f"paper:{paper_id}", {
                     "relevance_score": 0.8,  # Can be refined by LLM
                     "applied_at": datetime.now().isoformat()
                 })
    
    return decision_id
```
