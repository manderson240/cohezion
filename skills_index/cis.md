# CIS — Creative Innovation Studio

**Prefix:** `bmad-cis-*` | **Source:** `.claude/commands/bmad-cis-*.md`

## Agent Personas
`brainstorming-coach`, `creative-problem-solver`, `design-thinking-coach`, `innovation-strategist`, `presentation-master`, `storyteller`

## Skills

| Skill | Trigger | Notes |
|-------|---------|-------|
| `bmad-brainstorming` | "let's brainstorm", "ideation session" | Top-level command (not cis-prefixed) |
| `bmad-cis-design-thinking` | "design thinking workshop", "empathy mapping" | |

## Overlap Note

`bmad-brainstorming` vs `superpowers:brainstorming`:
- `superpowers:brainstorming` is a **meta-prompt enhancer** (runs before creative tasks)
- `bmad-brainstorming` is the **interactive workflow** (full facilitated session)
- Use both: superpowers auto-triggers, then bmad-brainstorming for deep sessions
