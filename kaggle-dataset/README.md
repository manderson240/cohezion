# ARC Prize 2026 — Compound Loop Submission

## Files
- `arc_solver.py` — DSL solver with 23 primitives + strategy selection
- `kaggle_submission_arc.py` — self-contained submission script
- `kaggle_notebook_minimal.ipynb` — minimal Kaggle notebook

## Usage
Upload `arc_solver.py` and the notebook to a Kaggle dataset.
The notebook imports the solver and generates `submission.json`.
