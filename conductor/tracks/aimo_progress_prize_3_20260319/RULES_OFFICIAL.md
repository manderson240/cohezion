# Official Rules: AI Mathematical Olympiad - Progress Prize 3

## General Rules
- **One account per participant:** Multiple accounts are not allowed.
- **No private sharing outside teams:** Privately sharing code or data outside of teams is not permitted.
- **Team Limits:** Maximum team size is 20 (based on latest rules).
- **Submission Limits:** 1 submission per day.

## Model Restrictions
- **Open-Weight Mandate**: AMLTs used at runtime must be open-weight.
- **Release Cutoff**: All runtime models must have been released prior to March 15, 2026.

## Winners Obligations
- **Open Source**: Winning submissions must be licensed under an OSI-approved license.
- **Reproducibility**: The solution must be fully reproducible.
- **Hosting**: The final model must be hosted on Hugging Face.
