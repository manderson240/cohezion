# Cohezion Product Guidelines

## 1. Vision & Tone

Cohezion is an elite, high-fidelity AI swarm orchestration system. The tone of voice should reflect this maturity:
- **Tone**: Professional, precise, academic yet forward-looking, highly technical.
- **Voice**: Authoritative, helpful, mentor-like.
- **Language**: Use clean, descriptive physics-grounded terminology (e.g., *coherence*, *attractors*, *manifolds*, *trajectories*, *precipitation*) to refer to platform components. Avoid dumbing down terminology; elevate the user's understanding instead.

## 2. Visual Style & Aesthetics

Cohezion's web interface must look **premium, modern, and state-of-the-art**. The styling guidelines are:

### Color Palette (HSL Tailored)
- **Primary / Void / Background**: Sleek dark mode using deep charcoal/obsidian HSL values.
  - Background: `hsl(220, 20%, 6%)`
  - Card/Container Background: `hsl(220, 20%, 10%)`
- **Accent (Coherence / Attractors)**:
  - Electric Blue / Cyan (Active / Normal): `hsl(190, 90%, 50%)`
  - Deep Purple (Manifold / Interpolation): `hsl(270, 80%, 60%)`
  - Quantum / Healing (Highlight): `hsl(160, 80%, 45%)`
- **Dissonance / Surprise (Alerts / Faults)**:
  - Crimson (Dissonance): `hsl(350, 80%, 55%)`

### Styling Elements
- **Glassmorphism**: Use semi-transparent card panels with backdrop blur filters for a multi-layered manifold depth effect.
  - `background: rgba(20, 24, 33, 0.65)`
  - `backdrop-filter: blur(12px)`
  - `border: 1px solid rgba(255, 255, 255, 0.08)`
- **Typography**: Clean, modern sans-serif fonts such as Inter, Outfit, or Roboto (from Google Fonts).
- **Animations & Micro-interactions**: Smooth, ease-in-out transitions (`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)`) for hovers, button clicks, and tab switching to make the interface feel responsive and alive.
