# CONCEPT: HIHO Stability (Half-In-Half-Out)

## Overview
HIHO Stability is the core governing principle of reality precipitation within the Cohezion manifold. It posits that absolute stability is not found in full manifestation (1.0 coherence) or absolute void (0.0 coherence), but at the precise midpoint.

## Key Principles
1.  **The 0.5 Coherence Rule**: Stable structures require exactly 50% overlap between the latent potential and the manifest substrate.
2.  **Quadrature Friction**: Interaction between these states generates the "friction" necessary for persistence.
3.  **Adversarial Resilience**: HIHO-compliant systems are resilient against external "reality shifts" because they maintain a tether to the void.

## Application in Cohezion
- **Idempotency**: All agent actions must be idempotent to prevent drifting from the 0.5 baseline.
- **Simulation**: Trajectory predictions aim for the 0.5 attractor.
