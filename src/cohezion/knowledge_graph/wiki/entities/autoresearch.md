# Entity: Autoresearch

## Abstract
Recursive optimization loop where AI agents act as researchers to optimize code (e.g., training scripts or kernels) within fixed wall-clock time budgets.

## Key Concepts
* **Fixed-Budget Benchmarking:** Standardizing evaluation by time to find hardware-optimal architectures.
* **Program-the-Program:** Humans edit the high-level strategy (`program.md`), while agents edit the implementation.
* **Minimalist Surface Area:** Restricting agent mutability to a single file to reduce search space.
