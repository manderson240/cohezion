# Entity: AutoHarness

## Abstract
Reliability framework for automatically synthesizing code harnesses (verifiers or policies) that prevent illegal or suboptimal agent moves in complex environments.

## Key Concepts
* **Code-as-Harness:** Synthesizing deterministic control loops to wrap model outputs.
* **Thompson Sampling Tree Search:** Treating harness generation as a search problem over programs.
* **Harness-as-Policy:** Distilling strategic reasoning into pure Python code for zero-cost inference.
