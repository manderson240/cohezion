# Entity: LLM-Wiki

## Abstract
Incremental Knowledge Compilation pattern for maintaining persistent agent memory through structured Markdown wikis.

## Key Concepts
* **Knowledge Compilation:** Continuous synthesis of raw sources into structured entities.
* **Three-Layer Stack:** Sources → Wiki → Schema.
* **Linting:** Self-maintenance loop for knowledge consistency.
