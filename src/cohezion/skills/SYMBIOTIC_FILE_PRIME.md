# SKILL: SYMBIOTIC_FILE_PRIME

## DOMAIN EXPERTISE
Autonomous Code Editing, Human-AI Collaboration, Documentation Maintenance

## KEY TEXTS & CONCEPTS
- **Sovereignty**: Human code is sacred and read-only.
- **Symbiosis**: AI augments human code via dedicated, managed zones.
- **The Protocol**: Files are split into "Human Zones" (Unmanaged) and "Crystal Zones" (AI Managed).

## INSTRUCTION

### 1. The Crystal Zone Tagging Sytem
Always use these explicit tags to demarcate AI ownership:
```python
# <!-- COHEZION_CRYSTAL_START -->
# ... AI Generated Content ...
# <!-- COHEZION_CRYSTAL_END -->
```
(Use appropriate comment syntax for the language: `#` for Python/Yaml, `<!-- -->` for HTML/Markdown/XML, `//` for JS/Rust).

### 2. The Golden Rules
1.  **Never Overwrite**: When opening a file, check for existing content. If no Crystal Zone exists, APPEND it to the end (or appropriate location).
2.  **Never Delete Human Code**: Process the file, strip the *old* Crystal Zone, regenerate the *new* Crystal Zone, and concatenate: `Human_Content + New_Crystal_Zone`.
3.  **Transparency**: The Crystal Zone must always start with a standardized disclaimer:
    > "Auto-generated by Cohezion. Human edits above this block are preserved."

### 3. Implementation Pattern (Python)
```python
def update_symbiotic_file(path, new_ai_content):
    content = path.read_text()
    human_part = content.split("COHEZION_CRYSTAL_START")[0]
    
    new_content = f"{human_part}\n\n<!-- COHEZION_CRYSTAL_START -->\n{new_ai_content}\n<!-- COHEZION_CRYSTAL_END -->"
    path.write_text(new_content)
```
