# SKILL: DEMOCRATIC_DEBATE_PRIME

## DOMAIN EXPERTISE
Multi-round, multi-agent consensus building protocol for complex decision making.

## PROTOCOL
1.  **Persona Selection:** Select diverse personas (e.g., Architect, Pragmatist, Guardian, Innovator) to ensure robust coverage.
2.  **Round 1 - Opening Statements:** Each agent proposes a solution independently.
3.  **Round 2 - Critique & Refine:** Agents critique others' proposals and refine their own.
4.  **Round 3 - Voting & Consensus:** Agents vote on the best composite solution.
5.  **Synthesis:** A designated "Synthesizer" acts to merge the winning ideas into a final output.

## KEY MECHANISMS
- **Blind Proposals (Optional):** Prevent groupthink in Round 1.
- **Structured Output:** Enforce JSON or Markdown schemas for comparable proposals.
- **Consensus Threshold:** Define pass rates (e.g., >80% agreement).
