## INSTRUCTION: THE MECHANISM PROTOCOL

When encountering any fringe physics claim:

1. **Strip the metaphor**: Identify the physical observables (what is actually measured)
2. **Find the mechanism**: What energy/force/field is doing the work?
3. **Classify the tier**: Confirmed anomaly (1), Theoretical frontier (2), Premature (3), Woo (4)
4. **Map to Smith**: Which of the 12 fabric dimensions is involved?
5. **Find the HIHO connection**: Does it involve a stability threshold or coherence condition?
6. **Connect to existing code**: Which file in `src/cohezion/` implements the nearest analog?

```python
def translate_fringe_claim(claim: str, observations: list[str]) -> dict:
    """
    Translate a fringe physics claim to a Cohezion-compatible mechanism.
    """
    # Step 1-2: Strip metaphor, find mechanism
    mechanism_keywords = {
        "charge_cluster": ["EVO", "itonic", "ball lightning", "charge cluster"],
        "quantum_coherence": ["coherence", "entanglement", "superposition", "decoherence"],
        "em_field": ["aether", "orgone", "scalar", "torsion", "zero point"],
        "toroidal": ["vortex", "toroidal", "spin", "rotation", "precession"],
        "consciousness": ["orch-or", "microtubule", "consciousness", "awareness"],
        "resonance": ["cymatics", "chladni", "432hz", "schumann", "morphic"],
    }

    detected = {}
    obs_text = " ".join(observations).lower()
    for mechanism, keywords in mechanism_keywords.items():
        if any(kw in claim.lower() or kw in obs_text for kw in keywords):
            detected[mechanism] = True

    # Step 3: Classify tier
    tier_1 = {"charge_cluster", "quantum_coherence"}  # Confirmed anomaly
    tier_2 = {"em_field", "toroidal", "consciousness", "resonance"}  # Frontier

    active = set(detected.keys())
    if active & tier_1:
        tier = 1
    elif active & tier_2:
        tier = 2
    elif detected:
        tier = 3
    else:
        tier = 4  # Woo: no recognized mechanism

    # Step 4-5: Map to Smith + HIHO
    smith_mapping = {
        "charge_cluster": "Control Fabric (Rotation+Precession+Charge at HIHO coherence)",
        "quantum_coherence": "Precipitation Fabric (Awareness → Particularization → Precipitation)",
        "em_field": "Field Fabric (Tempic + Electric + Magnetic)",
        "toroidal": "Control Fabric (SPIN = topological soliton)",
        "consciousness": "Precipitation Fabric dim 10 (Awareness = Orch-OR threshold)",
        "resonance": "Tempic Field (standing wave modes, 432Hz harmonic)",
    }

    return {
        "tier": tier,
        "actionable": tier <= 3,
        "mechanisms_detected": list(active),
        "smith_mapping": {m: smith_mapping[m] for m in active if m in smith_mapping},
        "recommendation": (
            "Investigate mechanism rigorously" if tier == 1
            else "Monitor experimental confirmation" if tier == 2
            else "Withhold judgment pending mechanism" if tier == 3
            else "Discard: no mechanism found"
        ),
    }
```
