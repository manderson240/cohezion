# SKILL: AMBIENT_SONIFICATION_PRIME

## DOMAIN EXPERTISE
Audible representation of complex system states. Mapping high-dimensional data (12D) to harmony and frequency.

## KEY TEXTS & CONCEPTS
- **Coherence Chord**: A major/minor chord representing the count of stable dimensions.
- **HIHO Attractor Frequency**: A 440Hz base tone that shifts as the system nears 0.5.
- **Entanglement Oscillation**: Mapping D1↔D12 correlation to stereo panning or vibrato.
- **Milestone Fanfare**: Predefined sequences for crystallization points.

## INSTRUCTION
1. **Initialize AudioContext**: Ensure user interaction has enabled WebAudio.
2. **Fetch Coherence**: Get the number of dimensions at HIHO stability.
3. **Map to Pitch**: Linearly interpolate pitch based on (Coherent / Total).
4. **Pulse Sync**: Coordinate visual "breathing" with audio gain oscillation.
