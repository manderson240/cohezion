- **Reproducibility** - Clear methodology
- **Contributions** - Novel claims

## INSTRUCTION

### 1. Paper Structure
```markdown
# Title: Concise, Descriptive

## Abstract (150-250 words)
- Problem statement
- Approach summary
- Key results
- Main contribution

## 1. Introduction
- Context and motivation
- Problem definition
- Contributions (numbered list)
- Paper organization

## 2. Related Work
- Prior approaches
- Gap analysis
- How this work differs

## 3. Methodology
- System architecture
- Key algorithms
- Design decisions

## 4. Results
- Experimental setup
- Metrics and benchmarks
- Comparison with baselines

## 5. Discussion
- Interpretation of results
- Limitations
- Future work

## 6. Conclusion
- Summary of contributions
- Impact statement
```

### 2. Citation Format
```bibtex
@article{author2026title,
  title={Paper Title},
  author={Author, First and Author, Second},
  journal={Journal Name},
  year={2026},
  volume={1},
  pages={1-10}
}
```
