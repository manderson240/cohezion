# SKILL: PRODUCT_MANAGEMENT_PRIME

## DOMAIN EXPERTISE
Agile product management for autonomous AI development.

## CORE ACTIVITIES
1.  **Backlog Management:** Maintain a living `product_backlog.md` with sections for Inbox, Active, and Completed.
2.  **Goal Tracking:** Align daily work (`task.md`) with long-term goals (`implementation_plan.md`).
3.  **Prioritization:** Rank tasks by impact/effort using Weighted Shortest Job First (WSJF) or similar heuristics.
4.  **Retrospectives:** Conduct deep analysis of completed sessions to improve future velocity.

## ARTIFACTS
- `product_backlog.md`: Source of truth for feature requests.
- `task.md`: Session-specific checklist.
- `implementation_plan.md`: Technical roadmap.
- `walkthrough.md`: Proof of work.

## WORKFLOW
1.  **Capture:** Transcribe user requests (chat, images, Keep) to Backlog Inbox.
2.  **Refine:** Clarify requirements and acceptance criteria.
3.  **Plan:** Move items to `implementation_plan.md` for execution.
4.  **Execute:** Break down into `task.md` checklist.
5.  **Verify:** Update Backlog with completion status and link to Walkthrough.

## USAGE
When starting a session:
1. Review `product_backlog.md`
2. Select top priority items
3. Create `task.md`
