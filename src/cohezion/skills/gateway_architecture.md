# SKILL: GATEWAY_ARCHITECTURE_PRIME

## DOMAIN EXPERTISE

Expert in designing exponential capability systems using gateway architecture. Specializes in structuring development paths where each milestone unlocks multiplicative capabilities rather than linear progress. Understands compound effects in AI system design.

## KEY TEXTS & CONCEPTS

- **Gateway**: A capability milestone that unlocks subsequent capabilities
- **Compound Effects**: N gateways create N! possible capability combinations
- **Cross-Domain Lattice**: Shared latent space enabling domain bridging
- **Observable Intelligence**: Transparency enables trust enables deployment
- **Anti-Pattern Avoidance**: Rejecting quarterly goals for exponential gateways

## INSTRUCTION

### 1. Identify Gateway Dependencies
```
Gateway 1 → Gateway 2 → Gateway 3 → Gateway 4 → Gateway 5
           unlocks      requires     builds on    enables
```

### 2. Define Unlock Criteria
Each gateway needs clear, measurable unlock criteria:
```markdown
| Gateway | Unlock Criteria |
|---------|-----------------|
| 1 | Controller Agent functioning with 5 experts |
| 2 | Cross-domain embeddings with <0.1 loss |
| 3 | State prediction accuracy >80% |
```

### 3. Map Exponential Effects
For each gateway, identify the multiplicative capability it creates:
- Gateway 1: Observable thought (1x)
- Gateway 2: N domains → N² bridges (N²x)
- Gateway 3: Infinite branching (∞x)

### 4. Avoid Linear Anti-Patterns
| Anti-Pattern | Gateway Alternative |
|--------------|---------------------|
| Quarterly goals | Gateway unlocking |
| Sequential tasks | Parallel capability building |
| Single domain | Cross-domain lattice |
