Findings

Test fixtures leaked into the production ledger Six event_type="T" rows from sources esc-plain / esc-emdash / esc-apostrophe_s, all with timestamp=1.0 — an escaping test suite wrote to the real data_product_event table. One root cause explains both the malformed type and the epoch-0 timeline bucket. Fix: point tests at a test db or mock the SQL boundary.
Two naming dialects on one bus UPPER-case enum names (bridge) and lower-case strings (ad-hoc publishers) for the same semantics. Harmless today; a consumer matching only one dialect silently misses half the traffic.
