## Implementation: warm_from_history(skill_name)

Follow the pattern from `warm_from_vault()`. The method should:
1. Return 0 early if no mcp_client
2. Search vault for execution patterns related to the skill: `mcp_client.vault_search(query=f"execution {skill_name} successful")`
3. Parse results — each result should have prompt/response data
4. Filter for successful executions (check for "success" or "coherence" > 0.7 in the pattern data)
5. Sort by quality (coherence score descending if available)
6. Load top performers into cache via `await self.cache.put(prompt=..., response=...)`
7. Return count loaded
8. Wrap everything in try/except, log errors, return 0 on failure

## Implementation: warm_from_recent_executions(limit)

Similar pattern:
1. Return 0 early if no mcp_client
2. Search vault for recent executions: `mcp_client.vault_search(query="recent execution high coherence")`
3. Parse results, extract prompt/response pairs
4. Limit to `limit` entries
5. Load into cache
6. Return count loaded
7. Non-blocking error handling
