## Phase 1: GEMM — Fused Quant+GEMM Triton Kernel

**Target**: Beat 24.4µs ranked by eliminating the separate `dynamic_mxfp4_quant` call (~16µs).

### Task 1.1: Create `gemm_fused_template.py`

New autoresearch template that generates a Triton kernel fusing:
1. Inline bf16→fp4 e2m1 quantization (using patterns from `triton-fp4-inline-quantization` skill)
2. `tl.dot_scaled` GEMM (using constraints from `amd-gfx950-tl-dot-scaled-constraints` skill)
3. B data reused from input (no re-quantization — B is already MXFP4)

**Parameterizable axes** (for K-Search tree):
- `BLOCK_M`: [16, 32, 64] (min 16 for gfx950)
- `BLOCK_N`: [32, 64, 128]
- `BLOCK_K`: [64, 128] (packed bytes, min 64 for `tl.dot_scaled`)
- `num_warps`: [4, 8]
- `num_stages`: [1, 2, 3]

**Key files to modify**:
- Create: `autoresearch/templates/gemm_fused_template.py`
- Modify: `autoresearch/generator.py` (register new template)

**Critical constraints** (from skills):
- BLOCK_M ≥ 16 (silent wrong results below)
- BLOCK_K ≥ 64 packed bytes (assertion failure below)
- RHS scale must be `[BLOCK_N, SCALE_PER_K]` (N-first)
- E8M0 formula: `floor(log2(amax / 6.0)) + 128` (NOT `floor(log2(amax)) + 127`)
- Nibble packing: sum-as-OR trick (no integer indexing in Triton)

### Task 1.2: Seed GEMM K-Search tree with fused strategies

## Phase 3: MLA — Flash Attention-Style Triton Kernel

**Target**: Moonshot — any improvement over 90.1µs. Eliminate 3-stage pipeline overhead.

### Task 3.1: Create `mla_flash_template.py`

Single-pass Flash Attention kernel adapted for MLA's K≠V dimensions:
- Q: [bs, num_heads, 576] (QK dimension)
- K: [total_kv, 576] (FP8 packed)
- V: [total_kv, 512] (V dimension, embedded in K)
- Output: [bs, num_heads, 512]

**Key challenge**: MLA has 576-dim QK but 512-dim V. Standard Flash Attention assumes QK_DIM == V_DIM. We need to:
1. Compute attention scores with Q·K^T (576-dim)
2. Apply softmax
3. Multiply attention × V (512-dim subset)

**Triton constraint**: 576 is NOT power-of-2. Must pad to 1024 for `tl.arange` (44% waste in registers).

**Parameterizable axes**:
- `BLOCK_KV`: [32, 64, 128] (KV sequence tiles)
- `num_warps`: [4, 8, 16]
- `num_stages`: [1, 2]

### Task 3.2: Seed MLA K-Search tree

Add flash-attention-style strategy nodes.

### Task 3.3: Hand-test correctness

MLA has relaxed tolerance (rtol=1e-1) — so FP8/approximation errors are acceptable.
