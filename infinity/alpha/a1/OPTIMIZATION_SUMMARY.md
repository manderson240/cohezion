## Analysis Summary

Analyzed `submission_custom_dispatch.py` (383 lines) targeting ~155µs performance.

### Key Bottlenecks Identified

1. **Parameter Selection Overhead** (Lines 175-177)
   - `_select_block_m()` and `_select_split_k()` called every invocation
   - ~3-5µs overhead, redundant for repeated shapes

2. **Buffer Cache Key Incomplete** (Line 123)
   - Missing device in cache key
   - Risk of cache misses on multi-GPU

3. **Dynamic Tensor Allocation** (Lines 218-280)
   - `tmp_out`, `out_stage1`, `a2` allocated fresh every call
   - ~8-12µs CUDA allocation overhead

4. **Scale View Recreation** (Lines 214-215)
   - `w1_scale.view()` called every invocation
   - ~1-2µs unnecessary overhead

5. **Dictionary Lookup Overhead** (Lines 186-201)
   - Multiple `bufs["key"]` lookups in hot path
   - ~1-2µs Python overhead

6. **Padding Computation** (Lines 179-183)
   - Deterministic values recomputed every call
   - ~1µs overhead

## Optimizations Applied
