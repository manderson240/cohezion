## Key Decisions

1. **Custom HIP over Triton**: Direct HIP gives better control over memory layout
2. **Fused 2-stage**: Single kernel launch eliminates intermediate buffer overhead
3. **ctypes wrapper**: Simple Python binding without pybind11 complexity
4. **Pre-shuffled weights**: Use existing CK layout for compatibility
