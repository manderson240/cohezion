# Serena MCP Plugin — Investigation & Recommendation

## Context

Serena is a Claude Code plugin (by Oraios) that provides semantic code analysis via Language Server Protocol (LSP). It's installed as a Claude Code plugin at `~/.claude/plugins/cache/claude-plugins-official/serena/`. It launches via `uvx --from git+https://github.com/oraios/serena serena start-mcp-server`.

**Problem**: Serena crashes on startup every session with:
```
SerenaConfigError: `projects` key not found in Serena configuration.
Please update your `serena_config.yml` file.
```
This causes a 30-second connection timeout on every Claude Code session start.

## Root Cause

The config at `~/.serena/serena_config.yml` is missing a required `projects` key. Serena's `SerenaConfig.from_config_file()` (line 751) raises `SerenaConfigError` if this key is absent. The config was likely created before Serena added this requirement.

**Current config** (`~/.serena/serena_config.yml`):
```yaml
language_backend: LSP
web_dashboard: true
web_dashboard_open_on_launch: false
# ... other settings, but NO projects key
```

**Fix** (if we want to keep Serena): Add a `projects` key pointing to the cohezion repo:
```yaml
projects:
  - /home/mike-anderson/dev/cohezion
```

## Recommendation: Remove Serena

**Serena is redundant.** Every capability it provides is already covered by existing tools, often better:

| Serena Capability | Already Covered By | Quality |
|---|---|---|
| Code navigation (go to definition, find references) | Built-in `LSP` tool in Claude Code | Equal or better |
| Semantic code search | `vexor search` (semantic) + `Grep`/`Glob` (exact) | Better (vexor has project-aware indexing) |
| Codebase understanding | Built-in `Read`, Explore agent, vexor | Better (native context) |
| Refactoring suggestions | Claude Code itself (direct code editing) | Better |
| Symbol lookup | Built-in `LSP` tool | Equal |

**Costs of keeping Serena:**
- 30-second timeout penalty on every session start (even when fixed, LSP init adds latency)
- Another LSP server running alongside Claude Code's built-in one (resource waste)
- Config maintenance burden (projects list must be updated per-repo)
- Plugin update risk (config format already broke once)

**The fix is trivial, but the value is near-zero.** Claude Code's built-in LSP + vexor + Grep already provide superior code intelligence with zero config.
