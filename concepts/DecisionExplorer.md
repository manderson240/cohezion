# Decision Explorer

A proposed interactive UI component for exploring architectural decisions in the GraphRAG knowledge graph. Provides semantic search and faceted filtering across all vault decisions.

## Intended Features

- Full-text semantic search across decisions
- Filter by status (proposed/accepted/rejected/deprecated)
- Cluster view by domain
- Side-by-side comparison of related decisions
