# Cloud Vault MCP

The cloud-vault-mcp server — HTTP MCP server on port 8360 providing programmatic access to the Cohezion vault. Implements VaultOps, CompoundOps, ObsidianOps, Teleport, SheetsBridge, and SurrealDB tools.
