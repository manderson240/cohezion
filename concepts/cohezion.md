# Cohezion

The Cohezion agentic AI framework — a compound engineering system for building knowledge-accumulating AI agent workflows. This vault is Cohezion's persistent knowledge base.

## Components
- **cloud-vault-mcp** — programmatic vault access
- **cohezion-engine** — workflow CLI (`cz`)
- **3d-graph-plugin** — Obsidian visualization
- **SurrealDB** — agent context graph
- **Ollama** — local model inference
