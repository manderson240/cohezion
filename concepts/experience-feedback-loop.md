# Experience Feedback Loop

The cycle by which agent session experience (successes, failures, discoveries) is captured, indexed, and injected back into future sessions to improve performance. Core to Cohezion's compound learning model.

## Stages
1. Session executes
2. Observations saved to memory
3. Lessons extracted to vault
4. Future sessions load prior context
