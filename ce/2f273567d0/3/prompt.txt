```python
class ModelTierPolicy(Enum):
    HOT = "hot"    # Always loaded, keep_alive=-1
    WARM = "warm"  # Loaded at startup, evictable under pressure
    COLD = "cold"  # On-demand only, evicted after timeout

@dataclass
class PooledModel:
    name: str
    tier: ModelTierPolicy
    size_gb: float
    loaded: bool = False
    healthy: bool = False
    last_used: float = 0.0
    error_count: int = 0
    avg_latency_ms: float = 0.0

class ModelPoolManager:
    """Lifecycle manager for 3-tier hot/warm/cold model rotation."""

    async def initialize(self) -> None           # Query /api/tags, reconcile with tier config
    async def ensure_loaded(self, model) -> bool  # Load if needed, evict cold if pressured
    async def health_check(self, model) -> bool   # Ping with trivial prompt, update status
    async def health_check_all(self) -> dict      # Check all loaded models
    def get_available_models(self) -> list         # Loaded + healthy models
    async def evict_model(self, model) -> bool     # Unload via keep_alive=0
    async def promote(self, model, tier) -> None   # cold→warm, warm→hot
    async def demote_under_pressure(self) -> list  # Evict lowest-priority when memory > 80%
    def get_pool_status(self) -> PoolStatus        # Summary snapshot
```

## Adversarial Review Protocol

### Tier 1 — Quick Lint (Claude haiku)

Checks: import hygiene, type hints, docstrings, test count >= 12, obvious errors (missing await, bare except). Fast — under 60s.

**Pass:** Zero blockers.

### Tier 2 — Deep Code Review (Claude sonnet)

Checks:
1. Concurrency safety (race conditions in ensure_loaded?)
2. Error handling (Ollama unreachable? model load fails?)
3. Resource leaks (httpx clients closed?)
4. Edge cases (all unhealthy, 100% memory, model stuck, unknown model)
5. Backward compatibility (CostAwareRouter change breaks nothing?)
6. Security (model name injection? timeouts enforced?)

**Pass:** Zero critical issues.

### Tier 3 — Architectural Review (Claude opus)

Checks:
1. Compound engineering (does this make future features easier?)
2. HIHO coherence (are tier transitions reversible?)
3. Charter compliance (observable, deterministic, honest metrics)
4. Integration coherence with DynamicModelRouter, OllamaModelManager, DynamicConcurrencyGate
5. Journey tracking (should pool emit 12D events?)
6. Token efficiency (health check overhead justified?)

**Pass:** No blocking concerns. Charter = ALIGNED. Compound score >= 0.7.

### Combined Verdict

```
ALL PASS → PASS (merge ready)
ANY CONDITIONAL_PASS → CONDITIONAL_PASS (fix conditions, then merge)
ANY FAIL → FAIL (rework required)
```
