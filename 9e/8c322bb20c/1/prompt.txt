## Key Decisions Made During Session

| Decision | Why | Alternative Rejected |
|----------|-----|---------------------|
| Streaming Ollama API | `urlopen` idle timeout kills non-streaming on CPU | Non-streaming (works only on GPU) |
| Cloud model for pi_plan | 1000x faster, 100% success rate | Local 7B (too slow for interactive) |
| No structured output for cloud | Cloud models ignore schema, better with prompt-only | Schema enforcement (empty responses) |
| Aggressive pruning prompt | Trees grew 20+ nodes/batch without pruning | Conservative pruning (tree bloat) |
| 30-node tree cap | Prevents unbounded growth in multi-hour runs | No cap (hundreds of low-quality nodes) |
| Split MAX_TOKENS (512 plan / 4096 code) | World model only needs ~100 tokens of JSON | Single budget (wasted on thinking tokens) |
| bf16 Phase 1 before MXFP4 Phase 2 | Validate sorting logic independently of fp4 | Direct to MXFP4 (harder to debug) |
| AGPL study-only for Unsloth | License prohibits copying code | Direct code reuse (license violation) |
