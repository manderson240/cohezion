## Context

`SyntheticFlumeDataset` was generating training data by sampling each feature from `N(0.5, 0.15)`. The rationale was to create a dataset quickly for integration testing without needing real agent runs. The model trained on this data achieved near-perfect reconstruction loss — which was celebrated as a success.

The problem: the model had learned to reconstruct Gaussian distributions. It had learned nothing about semantic agent state structure. When connected to real agent data, reconstruction quality collapsed because the real data distribution was completely different.

## Decision

Delete `SyntheticFlumeDataset`. Training data must come from actual agent interactions (simulation or real runs). Any synthetic data must be generated by a domain-realistic process, not random noise.

## Chosen Option

Use the overnight simulation pipeline to generate training data from actual FLUME agent runs. The 5.5M trajectory dataset becomes the canonical training source.

## Alternatives Considered

1. Keep SyntheticFlumeDataset but improve the generation process
2. Use random noise only for smoke tests, not for model training
3. Delete entirely and require real data for all training

## Decision Reasoning

### Why This Option?

A VAE is a universal function approximator for distributions — it will faithfully learn whatever distribution it's trained on. Training on random noise teaches it to model random noise. There is no valid use case for training a semantic model on semantically random data.

Using SyntheticFlumeDataset even for "just testing" created false confidence in training success and masked real data distribution issues.

### Alternatives Rejected

- **Improved generation** — Any synthetic generator that doesn't model real agent behavior still risks teaching the wrong distribution. The effort to make it realistic equals the effort to use real data.
- **Smoke tests only** — Acceptable in principle, but the history shows "just for testing" datasets get used as training data when real data is unavailable.

### Confidence Level

High. The empirical evidence (model fails on real data after training on noise) is unambiguous.

## Expected Outcomes

- Model learns actual agent state distribution
- Transfer to production works without distribution mismatch
- Training metrics reflect real-world performance

## Metrics & Impact

### Estimated

- Reconstruction quality on real agent data increases from collapsed to >0.85

### Actual (Post-Implementation)

- Training on 5.5M overnight trajectories produced meaningful semantic structure in latent space
