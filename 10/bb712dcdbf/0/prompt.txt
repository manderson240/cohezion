# Phase 3 Implementation Plan: 3D Graph Visualization Plugin

## Context

Phase 2 successfully delivered:
- **Track A**: SurrealDB agent reasoning schema (73/73 tests, 4 query patterns)
- **Track B**: Entire.io sync daemon (44/44 tests, real-time agent tracking)
- **Track C**: Lessons ↔ Decisions cross-validation (25 links, semantic proof)
- **Session 62**: Unblocking work — generated 8 semantic dimensions for all 84 papers via Ollama embeddings, enriched vault YAML with dimensional metadata

Phase 3 transforms this foundation into an interactive 3D visualization that makes the compound engineering knowledge base tangible and explorable.

**Problem**: 84 papers exist with rich semantic relationships, but no visual way to explore dimensional patterns (connectivity, depth, temporal positioning, domain clustering, etc.).

**Solution**: Custom Obsidian plugin that renders 84 papers as an interactive 3D graph, mapping 8 semantic dimensions to visual properties (position, color, size, opacity), with interactive search/filter controls.

**Outcome**: Users can visually explore paper relationships, understand dimensional clustering, discover papers by semantic proximity, and prepare for Phase 4 (decision analysis) + Phase 5 (operational dashboard).

## 8 Dimensions to Visualize

Each paper has been enriched with these 8 dimensions (stored in vault YAML frontmatter):

| Dimension | Scale | Visual Encoding | Purpose |
|-----------|-------|-----------------|---------|
| **Connectivity** | 0-1 | X-axis position | Network centrality (isolated ↔ hub papers) |
| **Conceptual_Depth** | 0-1 (theory↔applied) | Y-axis position | Theory vs practical (foundational ↔ applied) |
| **Temporal** | 0-1 (historical↔recent) | Z-axis position | Age (classic ↔ cutting-edge) |
| **Cross_Domain** | 1-15 (count) | Color hue (10 palettes) | Domain clustering (color = domain family) |
| **Completion** | 0-100% | Node size | Research maturity (0.5x-2.0x scale) |
| **Recency** | 0-1 | Opacity | Freshness (30%-100% opacity) |
| **Semantic_Similarity** | 0.0-0.5 | Edge weight | Neighbor similarity (computed, top-5 per paper) |
| **Similar_Papers** | [title, score] list | Link label | Interactive hover/click details |

### Step 3: 3D Visualization Engine (2 hours)

**Goal**: Render interactive 3D graph in Obsidian modal using Three.js.

**Resources**:
- 3D library: Three.js (already in Kyutai template)
- Physics simulation: D3-force (CPU-based force-directed layout in 3D)
- Canvas target: Obsidian Modal (from Kyutai)
- Camera controls: OrbitControls or custom pan/zoom/rotate

**Sub-tasks**:
1. Create `3DVisualization.ts`:
   - Initialize Three.js scene (camera, renderer, lights)
   - Create WebGL canvas in Obsidian Modal
2. Implement force-directed layout:
   - Use D3-force to compute positions based on:
     - **X-axis**: connectivity dimension
     - **Y-axis**: conceptual_depth dimension
     - **Z-axis**: temporal dimension
   - Physics: repulsive forces (papers spread out), attractive forces (semantic neighbors)
   - Run simulation 300 iterations or until converged (<2 seconds)
3. Create nodes for all 84 papers:
   - Geometry: Sphere (radius = sqrt(completion) for size variation)
   - Material: Color by cross_domain hue, opacity = recency
   - Label: Paper title on hover
4. Create edges for semantic neighbors:
   - Lines between papers, width = similarity score
   - Color = average hue of endpoints
5. Implement camera controls:
   - Orbit: Right-click drag
   - Zoom: Scroll wheel
   - Pan: Left-click drag or arrow keys
6. Add picking/raycasting:
   - Click paper → select (highlight + metadata panel)
   - Hover → show neighbors with glow effect

**Performance targets**:
- Graph settles in <2 seconds
- Maintain >30 FPS during interaction
- WebWorker for physics simulation (off-main-thread)
- Frustum culling for non-visible papers

**Success**: 3D graph renders, >30 FPS, camera responsive, node selection works, neighbors highlight on hover.

**Files**: `src/visualizations/3DGraph.ts`, `src/physics/ForceLayout.ts`, `src/rendering/ThreeRenderer.ts`
