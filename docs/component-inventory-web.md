### A2UI catalog (`src/a2ui/`)

9 declarative components + `A2UIRenderer`. These are **agent-driven** — the backend issues a declarative UI spec (A2UI v0.9, Apache 2.0) and the client instantiates it. Used for agent-authored experiences that don't hard-code a Three.js scene.

## Design system

- **Styling**: Tailwind via PostCSS (no standalone `tailwind.config.*` file required at default)
- **Icons / primitives**: `@react-three/drei` for 3D primitives; `clsx` for class composition
- **Animation**: Framer Motion 12 for 2D chrome transitions
- **Typography**: `@chenglou/pretext` for pretext/typography helpers; KaTeX for math

## Reusable vs specific

- **Reusable**: A2UI catalog, layout chrome, chart panels, KaTeX renderer, audio narrator hook
- **Specific**: Genesis 3D scenes (HologramField, BlochSphere, etc.) — tied to the 12D manifold data shape
