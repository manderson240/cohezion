## 1. Mathematical Formulation

Let an ARC task $\mathcal{T}$ be defined by demonstration pairs $\mathcal{D}_{\text{train}} = \{(X_i, Y_i)\}_{i=1}^m$ and test input $X_{\text{test}}$, where each grid $G \in \mathcal{M}_{H, W}(\mathcal{C})$ with dimensions $1 \le H, W \le 30$ and discrete color palette $\mathcal{C} = \{0, 1, \dots, 9\}$.

### 1.1 Dihedral Stabilizer Group $G_{\text{task}} \le D_4$
The group $D_4$ contains 8 elements generated by rotation $r$ (by $\pi/2$) and reflection $s$:
$$D_4 = \{R_0, R_{90}, R_{180}, R_{270}, S_H, S_V, S_D, S_{AD}\}$$

For an arbitrary grid $G$:
- $R_{90}(G)[r, c] = G[H - 1 - c, r]$
- $S_H(G)[r, c] = G[H - 1 - r, c]$
- $S_V(G)[r, c] = G[r, W - 1 - c]$
- $S_D(G)[r, c] = G[c, r]$

**Definition (Task Internal Symmetry Stabilizer)**:
$$G_{\text{task}} = \bigcap_{i=1}^m \{ g \in D_4 \mid g(Y_i) = Y_i \}$$

**Directional Gravity Vector**:
$$\vec{A}_i = \operatorname{CoM}(Y_i \setminus \{c_{\text{bg}}\}) - \operatorname{CoM}(X_i \setminus \{c_{\text{bg}}\})$$
If $\|\vec{A}_i\| > 0$ and $\frac{\vec{A}_i}{\|\vec{A}_i\|} \approx \vec{u}$ across all $i$, directional anisotropy is active. Any $g \in D_4$ where $g(\vec{u}) \ne \vec{u}$ is excluded from the stabilizer constraint.

### 1.2 Color Conservation Envelopes
Let $\mathbf{h}(G) \in \mathbb{N}^{10}$ denote the color histogram vector:
$$h_c(G) = \sum_{r=0}^{H-1} \sum_{c_x=0}^{W-1} \mathbb{I}(G[r, c_x] = c)$$
$$\operatorname{Palette}(G) = \{c \in \mathcal{C} \mid h_c(G) > 0\}$$

- **Palette Envelope**: If $\forall i, \operatorname{Palette}(Y_i) \subseteq \operatorname{Palette}(X_i)$, candidate must satisfy $\operatorname{Palette}(\hat{Y}) \subseteq \operatorname{Palette}(X_{\text{test}})$.
- **Marker Delta**: If $\forall i, \operatorname{Palette}(Y_i) \setminus \operatorname{Palette}(X_i) = \{c^*\}$, candidate must satisfy $\operatorname{Palette}(\hat{Y}) \subseteq \operatorname{Palette}(X_{\text{test}}) \cup \{c^*\}$.
- **Mass Invariance**: If $\forall i, \forall c \ne c_{\text{bg}}, h_c(Y_i) = h_c(X_i)$, candidate must satisfy $h_c(\hat{Y}) = h_c(X_{\text{test}})$.

### 1.3 Digital Euler Characteristic Conservation
For a binary grid mask $B \in \{0, 1\}^{H \times W}$, the Euler characteristic $\chi(B)$ under 4-connectivity is computed from the frequencies of $2 \times 2$ bit-quad configurations ($Q_1, Q_2, Q_3, Q_4, Q_D$):
$$\chi(B) = \frac{1}{4}(Q_1 - Q_3 + 2 Q_D) = b_0(B) - b_1(B)$$
where $b_0$ is the number of connected components and $b_1$ is the number of enclosed cavities.

- If $\Delta \chi^{(i)} = \chi(Y_i) - \chi(X_i) = \delta$ is constant $\forall i$, any candidate with $\chi(\hat{Y}) - \chi(X_{\text{test}}) \ne \delta$ is deterministically pruned.
