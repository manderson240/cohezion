P2
VJEPA probabilistic predictor — JEPAWorldModel.predict returns (mu, sigma)
Claim: replacing point-estimate prediction with a distribution enables JepaGate to use uncertainty as a confidence proxy for PROCEED vs. REROUTE. Depends on P1-B — sigma is meaningless before the model has trained on real data.
Build
  • Req — JEPAWorldModel.predict(s_t, a) → (mu, sigma); sigma wired into JepaGate.check() as coherence proxy
  • Design — variational predictor head: linear → (mu, log_var); sigma = exp(0.5 * log_var); KL term in train_step(). Source: VJEPA arXiv:2601.14354 + CDiT arXiv:2603.14482
  • JepaGate — coherence = 1 / (1 + sigma.mean()) → high uncertainty → REROUTE. Uses existing coherence_threshold property (JTP1)
  • Backward compat — single-tensor callers receive mu; sigma is additive
Verify
  • Structural test — assert 'sigma' in inspect.signature(JEPAWorldModel.predict).parameters; catches signature drift before behavioral tests run
  • Discriminating test — high-noise input → sigma > low-noise input; wrong impl (constant sigma=1) → both equal → FAIL
  • Consumption proof — neutralize sigma (constant 1.0) → JepaGate routing unchanged → FAIL. If this test passes, sigma is not consumed
  • Adversarial — independent agent traces sigma from predict() through JepaGate to an actual routing decision; documents every intermediate consumer
  • Boundary smoke — live JEPA train step on 5 real trajectories; assert sigma.mean() > 0
◐ DESIGN PHASE — research banked (arXiv:2601.14354, 2603.14482); ~4 h; implement after P1-B
Cross-cutting V-model rules — apply to all five
Rule 1
Test the claim, not the component
Write the falsifying command before any code. If the mechanism is wrong the test must fail. A green test that cannot fail proves nothing about the system.
Rule 2
Consumption, not declaration
A capability is wired only when a production consumer reads it and acts on it. Grep for non-test, non-def uses of every producer. No consumer = dormant.
Rule 3
Un-mocked boundary smoke
One live probe per real boundary before declaring done. Wrong port, empty sigma, or bad threshold are invisible to mocked tests — only a live call catches them.
Rule 4
Break author–test correlation
The agent that builds the fix must not sign off on it. Route to an independent QA agent with "assume broken" framing. A producer's green self-test is a claim, not QA.
