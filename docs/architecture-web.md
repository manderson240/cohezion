# Architecture – Web (`src/web/anima_dashboard/`)

_Generated by BMAD `/bmad-document-project` on 2026-04-22._

## Executive summary

**Anima Dashboard** is the Genesis UI for Cohezion — a Next.js 16 App Router application that visualizes the 12-dimensional agent universe in real time using Three.js, streaming data from the FastAPI backend via REST, SSE (AG-UI), and WebSockets (`/pulse`). It also hosts a declarative **A2UI catalog** that renders agent-generated UI experiences.

## Architecture pattern: Component-driven 3D + A2UI

Two composition layers:

1. **Hard-coded Genesis UI** (`src/app/` + component tree): 11 components across 8 tabs at `/genesis` — BlochSphere, GenesisScene, FlumeLatentViz, SwarmTopologyViz, HologramField, etc.
2. **A2UI catalog** (`src/a2ui/`): 9 declarative components driven by agent-authored experience scripts (Google A2UI v0.9, Apache 2.0). The backend emits a declarative UI spec; the `A2UIRenderer` instantiates it client-side.

```
User → Next.js App Router
         │
         ├── /genesis route (8 tabs, 11 3D/2D components)
         │      │
         │      ├── HologramField      ← GET /universe/nodes
         │      ├── BlochSphere
         │      ├── GenesisScene
         │      ├── FlumeLatentViz     ← GET /flume/*
         │      ├── SwarmTopologyViz
         │      └── WalletWidget       ← GET /wallet
         │
         ├── A2UIRenderer                 ← server-pushed declarative UI
         │      (9 component catalog, Apache 2.0)
         │
         ├── useOuroboros hook            ← WS /pulse (12D state vectors)
         │
         └── AG-UI event consumer         ← SSE /api/agui/stream (15+ typed events)
```

## Data flow (web ↔ backend)

| Channel | Endpoint | Direction | Purpose |
|---|---|---|---|
| REST | `GET /universe/nodes` | Web → Backend | HologramField node coordinates (12D projected) |
| REST | `GET /wallet` | Web → Backend | Ascension credit balance |
| REST | `POST /simulate/step` | Web → Backend | Advance simulation one step |
| REST | `GET /health` | Web → Backend | System vitals |
| REST | `GET/POST /journeys/*` | Web → Backend | Journey CRUD + status |
| REST | `GET /flume/*` | Web → Backend | FLUME latent-space ops |
| SSE | `GET /api/agui/stream` | Backend → Web | Typed AG-UI event streaming |
| WS | `/pulse` | Backend → Web | 12D state vector stream for `useOuroboros` |

## Deployment

The web app is packaged alongside the backend; static assets may be served by the FastAPI app via `src/cohezion/api/static/`. Production build: `bun run build` then serve via Next.js `bun run start`, or copy built output to the backend's static mount. See [`deployment-guide.md`](./deployment-guide.md).

## Testing strategy

- Playwright e2e under `src/web/anima_dashboard/tests/`
- CI: `.github/workflows/playwright.yml`
- Run locally: `bun run test:e2e`
- Test results land in `playwright-report/` and `test-results/`

## Known constraints

- **Hardware**: Target is AMD Radeon 8060S iGPU + 128 GiB unified memory. WebGL scenes should not assume discrete GPU VRAM.
- **CSS**: Tailwind is wired via PostCSS (no separate Tailwind config file emitted by default).
- **A2UI fidelity**: A2UI renderer must remain compliant with Google A2UI v0.9 (Apache 2.0) to allow backend-agnostic experience scripts.
