## Storage architecture

Three tiers (per `CLAUDE.md` "Data Storage Architecture for Simulations" + the `cohezion-data-governance` skill):

| Tier | Used for | Access |
|---|---|---|
| **Git** | Source code, small configs, PRIME skills (`.md` + `.py`), plan docs | Versioned via git |
| **SurrealDB** | Journeys, traces, metrics, hash chains, V-Model gates, skill metadata | `ws://localhost:8001?versioned=true` |
| **External (LFS / vault / external)** | Large binaries, tensors, embeddings caches | Git LFS (`.gitattributes`) + `~/vaults/cohezion-vault/` |

Pre-commit hook blocks files > 50 MB unless Git LFS-tracked (`.gitattributes` covers `*.so`, `*.whl`, `*.pt`, `*.pth`, `*.pkl`, `*.tar.gz`, `*.bundle`, `*.jsonl`). Current bundle size: 182 MB (down from 14 GB before LFS migration).

## Primary database: SurrealDB (SurrealKV)

- **Backend**: SurrealKV (migrated from RocksDB in Session 96b)
- **Connection**: `ws://localhost:8001?versioned=true`
- **Host**: `127.0.0.1` only
- **Feature flags**: `versioned=true` enables VERSION clause for temporal queries.

Clients:
- `src/cohezion/persistence/surreal_logger.py` — primary write path
- `src/cohezion/persistence/genesis_persistence.py` — genesis state
- `src/cohezion/persistence/obsidian_mcp.py` — Obsidian vault bridge

## Migrations

No Alembic / Prisma / Flyway setup — schema evolution is tracked in code under `src/cohezion/persistence/` and by explicit migration scripts in `scripts/` (when they exist). For version bumps, the V-Model G5 gate requires a proof obligation on schema compatibility.

## Pydantic models

All boundary validation uses Pydantic v2 (`src/cohezion/models/`, `src/cohezion/config/`, `src/cohezion/api/` request/response models). Per `CLAUDE.md`: **validation at boundaries** (input/output), with assertions for internal invariants.

## Git LFS coverage (binary data)

46 files under Git LFS:
- `*.so` (compiled extensions)
- `*.whl` (wheels)
- `*.pt`, `*.pth` (torch checkpoints — e.g. `data/rl/checkpoints/policy_final.pt`)
- `*.pkl` (pickles)
- `*.tar.gz`, `*.bundle` (archives)
- `*.jsonl` (large JSONL datasets)

Pre-commit `lfs-pointer-check` hook enforces that large binaries do not leak into regular git objects.
