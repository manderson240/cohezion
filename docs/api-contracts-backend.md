# API Contracts – Backend

_Generated by BMAD `/bmad-document-project` on 2026-04-22 (quick scan — catalog only, not full request/response schemas)._

## Overview

- **App**: FastAPI (`>=0.104.0`) on port `:8080`
- **Entry points**: `src/cohezion/api.py` (legacy root app) and `src/cohezion/api/main.py` (modular)
- **Route count**: 92 handlers (from `CLAUDE.md`)
- **Auth**: `src/cohezion/api/security.py` — JWT via `pyjwt`, passwords via `passlib[bcrypt]`
- **Static**: `src/cohezion/api/static/` serves built Three.js / WASM frontend artifacts
- **Observability**: `src/cohezion/api/observability_endpoints.py` + `telemetry.py`

For full request/response shapes run: `uv run uvicorn cohezion.api:app --reload` then open `http://localhost:8080/docs` (FastAPI auto-generated OpenAPI/Swagger).

## Route families

### Root app (`src/cohezion/api.py`)

Documented in the module docstring as the Three.js + WASM frontend backend:

| Method | Path | Purpose |
|---|---|---|
| GET | `/universe/nodes` | 12D node data for `HologramField` visualization |
| GET | `/wallet` | Ascension credit balance for `WalletWidget` |
| WS | `/pulse` | Streaming 12D state vectors for `useOuroboros` |
| POST | `/simulate/step` | Advance simulation one step |
| GET | `/health` | System vitals (`ResourceMonitor`) |

### AG-UI (`src/cohezion/api/agui_events.py` + `api/routes/agui.py`)

AG-UI protocol (CopilotKit, Apache 2.0) — typed Server-Sent Events.

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/agui/stream` | SSE stream of 15+ typed event types |

15+ event types defined in `agui_events.py`. Client consumer lives in the Anima dashboard.

### Journeys (`src/cohezion/api/journeys.py`, `journey_status.py`)

| Method | Path | Purpose |

| POST | `/journeys` | Start a new journey |
| GET | `/journeys/{id}` | Fetch a journey |
| GET | `/journey_status/{id}` | Current status (position, coherence, health) |
| POST | `/journeys/{id}/checkpoint` | Save checkpoint |
| POST | `/journeys/{id}/rollback` | Restore from checkpoint |

## Authentication

- **Scheme**: JWT (pyjwt) with bcrypt-hashed passwords (passlib)
- **Middleware**: `src/cohezion/api/security.py`
- **Token header**: `Authorization: Bearer <jwt>`
- **MCP servers** have their own access-control tier via the MCP Registry (tier access + call tracking) — see `src/cohezion/data_mesh/`.

## SSE queue bounds

`src/cohezion/api/sse_queue_bounds.py` enforces backpressure on AG-UI SSE streams — bounded queue per client to prevent runaway memory when clients disconnect silently.

## Failure hooks

`src/cohezion/api/fail_hook.py` — intercepts API failures and routes them to `DegradationDetector` for thermal/quality feedback (closes the loop back into the `CostAwareRouter`).

## Streaming primitives

`src/cohezion/api/streaming.py` — shared SSE / WebSocket streaming helpers.
