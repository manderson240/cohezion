## Integration points

| # | From | To | Type | Endpoint | Purpose | Payload shape |
|---|---|---|---|---|---|---|
| 1 | web | backend | REST | `GET /universe/nodes` | HologramField 12D node data | Array of node records |
| 2 | web | backend | REST | `GET /wallet` | Ascension credit balance | `{balance, currency}` |
| 3 | web | backend | REST | `POST /simulate/step` | Advance one simulation step | `{agent_id, …}` |
| 4 | web | backend | REST | `GET /health` | System vitals | `ResourceMonitor` snapshot |
| 5 | web | backend | REST | `GET /journeys/{id}` | Fetch journey | Journey record + 12D trajectory |
| 6 | web | backend | REST | `POST /journeys/{id}/checkpoint` | Save checkpoint | `{checkpoint_id}` |
| 7 | web | backend | REST | `POST /journeys/{id}/rollback` | Restore checkpoint | `{restored_to}` |
| 8 | web | backend | REST | `GET /flume/*` | FLUME VAE ops | Latent vectors |
| 9 | backend | web | **SSE** | `GET /api/agui/stream` | Typed AG-UI events | 15+ event types, see `agui_events.py` |
| 10 | backend | web | **WebSocket** | `/pulse` | 12D state vector stream | Per-tick vector for `useOuroboros` |

## Protocols used

| Protocol | Standard | Role in cohezion |
|---|---|---|
| **MCP** | Model Context Protocol | 87+ tools (cloud-vault-mcp, compound-mcp, maintenance-mcp). Backend-internal — not exposed to web. |
| **A2A** | Agent-to-Agent | 7 specialist agents with `.well-known/agent.json` cards |
| **A2UI** | Google A2UI v0.9 (Apache 2.0) | Declarative UI — backend emits spec, web renders via `A2UIRenderer` (9-component catalog) |
| **AG-UI** | CopilotKit AG-UI (Apache 2.0) | Typed SSE event transport (15+ types) |
| **UCP / AP2** | Commerce protocols | N/A (not used) |

## Data flow example: agent journey

1. Web hits `POST /journeys` — backend creates `agent_journey` record (SurrealDB, bi-temporal).
2. `CompoundExecutor` runs 11-step pipeline.
3. Each step:
   - `JourneyTracker.record_state(…)` → SurrealDB
   - `JourneyTracker.record_transition(…)` → SurrealDB + hash chain
   - Emits AG-UI event → `/api/agui/stream` (SSE) → web consumer
4. `useOuroboros` hook receives 12D state vectors on `/pulse` (WS) in parallel.
5. Web renders `ManifoldTrajectoryViz` + `BlochSphere` + `HologramField` updates.
6. On completion, `RetrospectionEngine` + `SkillRefiner` run; skill definition updates propagate via `SkillConsensusVoter`.

## Shared dependencies

- **None code-shared** between web and backend — TypeScript types are not generated from Pydantic models. AG-UI event types are defined in `src/cohezion/api/agui_events.py` (Python) and consumed in `src/web/anima_dashboard/` (TS) — these must be kept in sync manually.
- **Apache 2.0 third-party contracts** they both implement:
  - AG-UI event schema
  - A2UI component catalog

## Single-origin deployment

For production, the web build can be served as static assets by FastAPI under `src/cohezion/api/static/`. This avoids CORS + gives single-origin auth. See [`deployment-guide.md`](./deployment-guide.md).
