01 The three concurrent loops

Three self-paced agents share one repo and one turn-queue. They never run truly in parallel (one session, serialized), but they interleave — each holds its own ledger, its own guardrail, and its own non-destructive contract.

Each loop writes a different durable artifact. The contracts are intentionally asymmetric: the build loop changes code behind a falsifiable check; the wiring loop only adds static import edges; the research loop only touches two docs and never fabricates an id.

03 Architecture: the sense→act→record→tune→grow arc

The C-thread items aren't isolated features — they close a loop. Routing produces a signal, the signal proposes a specialist (human-gated), and survivors are deposited as addressable neurons in the existing SurrealDB graph. "Local inference forms new neurons" was grounded against real code: the neurons table already grows from Learnings; items 15–16 added inference and skill as new country values rather than building a parallel graph.

Discriminating invariant that holds the arc honest (harness CB-class): a skill that fails the value gate deposits zero neurons; one that passes deposits exactly one. Under pytest the real graph is never written (path-injection skip pattern).
