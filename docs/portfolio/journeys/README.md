# Agentic Journeys: 12D Trajectory Tracking

## Overview
The Journey Tracker maps compound execution quality metrics to 12D FLUME axiomatic trajectories, enabling experience-guided agentic workflows with quantified coherence.

## The 12 Dimensions

3D (x, y, z)
1D (t)
8D (theoretical framework)

**Projection:** Holographic (2048D → 12D)

## Quality Scoring

The trajectory quality score combines three key metrics:

```
Quality = (coherence × 0.5) + (smoothness × 0.3) + (convergence × 0.2)
```

Where:
- **Coherence (Agent skill alignment (0.0-1.0)):** How well the trajectory aligns with agent skills
- **Smoothness (Trajectory continuity (0.0-1.0)):** Continuity of the trajectory path
- **Convergence (Goal-directedness (0.0-1.0)):** Goal-directedness and completion
