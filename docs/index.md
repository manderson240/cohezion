## Project overview

- **Type:** Monorepo with 2 parts
- **Parts:**
  - `backend` — Python 3.11 / FastAPI / SurrealDB (`src/cohezion/`)
  - `web` — Next.js 16 / React 19 / Three.js (`src/web/anima_dashboard/`)
- **Primary language (backend):** Python 3.11
- **Primary language (web):** TypeScript
- **Architecture:** Compound engineering loop over a 12D Riemannian manifold; safety-as-physics rather than safety-as-reward-penalty
- **License:** MIT
- **Repository:** [manderson240/cohezion](https://github.com/manderson240/cohezion)

## Getting started

### New AI agent (first session)

1. Read [`../CLAUDE.md`](../CLAUDE.md) (canonical working reference).
2. Scan this index and [`project-overview.md`](./project-overview.md).
3. Read [`../HARDWARE_PROFILE_PRIME.md`](../HARDWARE_PROFILE_PRIME.md) (ROCm, not CUDA).
4. Read the constitution + charter (`.agent/`).
5. Check `git branch --show-current` before touching anything.

### New human contributor

1. Read [`../README.md`](../README.md).
2. `uv sync`; `git lfs install && git lfs pull`.
3. `make validate` to confirm your environment.
4. Read [`contribution-guide.md`](./contribution-guide.md).
5. Pick a `develop`-based branch and follow conventional-commit style.

### Feature planning (brownfield)

1. Point the PRD workflow at this index: `docs/index.md`.
2. For **UI-only** features → reference [`architecture-web.md`](./architecture-web.md) + [`component-inventory-web.md`](./component-inventory-web.md).
3. For **API-only** features → reference [`architecture-backend.md`](./architecture-backend.md) + [`api-contracts-backend.md`](./api-contracts-backend.md).
4. For **full-stack** features → reference both + [`integration-architecture.md`](./integration-architecture.md).
5. If touching data models → reference [`data-models-backend.md`](./data-models-backend.md).

### Running & developing

```bash
make help                 # see all Make targets
make validate             # 23-check compound-loop gate
make test                 # 6,369 tests
uv run uvicorn cohezion.api:app --reload      # API at :8080
cd src/web/anima_dashboard && bun run dev     # web at :3000
```
