# Cohezion – Project Overview

_Generated by BMAD `/bmad-document-project` on 2026-04-22 (initial_scan, quick)._

## What it is

**Cohezion** is a compound-AI orchestration platform: a Python backend that trains and evaluates agents inside a 12-dimensional Riemannian manifold (Lagrangian mechanics + SU(2) gauge theory + HIHO stability), paired with a Next.js "Anima" dashboard that visualizes the universe in real time. Agents learn within an environment whose *physics itself* provides safety guarantees, rather than relying on penalty-shaped rewards.

Tagline (from README): _"Physics-grounded training universes for safe AI agents."_

## Architecture pattern

- **Backend**: Modular service-oriented monolith, 84 top-level `src/cohezion/*` subpackages grouped by capability (compound, swarm, physics, flume, persistence, world_model, governance, …). Core flow = **Compound Engineering Loop** (see `docs/architecture-backend.md`).
- **Web**: Next.js App Router + component-driven 3D canvas. 11 Genesis UI components across 8 tabs under `/genesis`.
- **Communication**: REST + SSE (AG-UI) + WebSocket (`/pulse`) from web → backend.

## Hardware constraints (important)

Runs on **AMD Ryzen AI MAX+ 395 (Strix Halo)** — 16C/32T CPU + Radeon 8060S iGPU + 128 GiB LPDDR5X unified memory. Torch is **ROCm-built**, not CUDA. Never assume RTX/CUDA — see `HARDWARE_PROFILE_PRIME.md`.
