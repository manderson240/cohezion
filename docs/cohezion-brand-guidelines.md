The definitive brand identity system for the COHEZION platform — distilled from the vault's compound engineering philosophy, agentic AI architecture, and ecological-technological visual language.

| Element | Value |
|---------|-------|

## Color System — "Circuit Moss Palette"

### Primary — The Deep Field
- **Void** `#0A0A0A` — Page background
- **Substrate** `#0D1117` — Card/container background
- **Carbon** `#161B22` — Code block background
- **Graphite** `#21262D` — Borders, dividers

### Secondary — Circuit Moss
- **Biolume** `#00E676` — Primary action, success, energy
- **Chlorophyll** `#2ECC71` — Secondary green
- **Canopy** `#27AE60` — Tertiary green
- **Lichen** `#1E8449` — Dark accent green
- **Deep Moss** `#145A32` — Deepest green

### Accent — Orbital Cyan
- **Orbital** `#00BCD4` — Secondary action, links
- **Atmosphere** `#26C6DA` — Hover states
- **Aurora** `#4DD0E1` — Strings in code
- **Ice** `#80DEEA` — Light accent

### Signal — Earth Core
- **Terra** `#3498DB` — Data visualization, info
- **Ocean** `#2980B9` — Charts
- **Sapphire** `#1A5276` — Deep data

### Metallic — Gear & Lattice
- **Chrome** `#BDC3C7` — Body text
- **Titanium** `#95A5A6` — Secondary text
- **Steel** `#7F8C8D` — Tertiary text
- **Iron** `#566573` — Captions, line numbers
