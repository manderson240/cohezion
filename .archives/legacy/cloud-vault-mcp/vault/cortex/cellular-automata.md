# Cellular Automata

## Definition

A cellular automaton (CA) is a discrete computational model consisting of a regular grid of cells, each in one of a finite number of states, that evolves in discrete time steps according to a local update rule. Each cell's next state depends only on its current state and the states of its immediate neighbors. Despite this purely local interaction, CAs can produce arbitrarily complex global behavior — including universal computation.

Formally, a one-dimensional CA is a tuple (S, N, f) where:
- S is a finite state set (e.g., {0, 1})
- N is the neighborhood template (e.g., {-1, 0, 1} for nearest-neighbor)
- f: S^|N| -> S is the local update rule

The global dynamics arise from applying f simultaneously to every cell at each time step t:

> s_i(t+1) = f(s_{i+n_1}(t), s_{i+n_2}(t), ..., s_{i+n_k}(t))

## Key Properties

- **Locality:** Each cell updates based only on its immediate neighborhood. No long-range communication is required. Global patterns emerge purely from local interactions.
- **Determinism:** Given the initial configuration and the rule, the entire future evolution is determined. Yet deterministic rules can produce behavior that is computationally irreducible — there is no shortcut to predict the outcome without running the simulation.
- **Universality:** Wolfram's Rule 110 (k=2, r=1 elementary CA) was proved Turing-complete by Matthew Cook (2004). Any computation that can be performed by a Turing machine can be embedded in this single-rule CA.
- **Wolfram's Four Classes:** Stephen Wolfram classified CA behavior into four classes:
  - **Class 1:** Evolution leads to a homogeneous state (fixed point)
  - **Class 2:** Evolution leads to simple periodic structures
  - **Class 3:** Evolution produces chaotic, aperiodic behavior (pseudo-random)
  - **Class 4:** Evolution produces complex localized structures and long-range correlations (edge of chaos — where computation happens)
- **Reversibility:** Most CAs are irreversible (information is destroyed). Reversible CAs (bijective global maps) conserve information and have physical significance as models of conservative dynamics.

## Mathematical Framework

### Elementary Cellular Automata (Wolfram notation)

For k=2 states, r=1 radius: each of the 2^3 = 8 possible neighborhood configurations maps to a 0 or 1 output. The rule number is the decimal encoding of this 8-bit output string.

Example — Rule 110:

| Neighborhood | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
|---|---|---|---|---|---|---|---|---|
| Output | 0 | 1 | 1 | 0 | 1 | 1 | 1 | 0 |

Binary: 01101110 = 110 in decimal.

Rule 110 produces Class 4 behavior: persistent structures (gliders), collisions that produce complex interactions, and Turing-completeness.

### Conway's Game of Life (2D, totalistic)

State set S = {0, 1} (dead/alive). Moore neighborhood (8 neighbors). Totalistic rule:
- A live cell with 2 or 3 live neighbors survives
- A dead cell with exactly 3 live neighbors becomes alive
- All other cells die or stay dead

The Game of Life is Turing-complete and supports universal construction (replicators, logic gates, memory).

### Entropy and Information in CAs

The spatial entropy of a 1D CA configuration c at time t:

> H(t) = -sum_w P(w, t) * log_2(P(w, t))

where P(w, t) is the probability of finding window pattern w in the configuration at time t. Class 3 CAs maximize entropy; Class 4 CAs maintain intermediate entropy with localized structure.

## Examples

- **Rule 30:** Class 3 (chaotic). Used by Wolfram for pseudorandom number generation. The central column passes statistical randomness tests despite being generated by a simple deterministic rule.
- **Rule 110:** Class 4 (complex). Turing-complete. Produces persistent "spaceships" that interact in computable ways.
- **Langton's Ant:** A 2D CA where a single ant on a grid produces chaotic behavior for ~10,000 steps, then spontaneously generates a persistent highway structure — an emergent order-from-chaos transition.
- **Lattice gas automata:** CAs used to simulate fluid dynamics. The FHP model (Frisch-Hassleben-Pomeau, 1986) on a hexagonal lattice recovers the Navier-Stokes equations in the continuum limit.
