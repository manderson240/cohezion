## Problem

Predicting a single "most likely" next trajectory position is insufficient for decision support. In agent behavior analysis, you want to explore the space of plausible futures — not just the most likely path, but the range of paths that are consistent with current momentum and recent history. This enables:
- Risk assessment (could this trajectory reach a dangerous region?)
- Intervention planning (what perturbation would redirect toward a better outcome?)
- Ensemble-based uncertainty quantification

## Solution

Extend momentum-based trajectory prediction with a branching mechanism that generates N parallel counterfactual futures. Each branch represents a plausible trajectory under a different perturbation of the current momentum vector. Branches are generated by sampling from the orthogonal complement of the momentum direction.

Key design choices:
- **Orthogonal perturbations**: Perturbations perpendicular to current momentum preserve forward motion while exploring lateral variation
- **Magnitude scaling**: Branch spread controlled by perturbation scale; larger = more diverse, less realistic
- **Branch pruning**: Discard branches that enter known-anomalous regions or violate physical constraints

## Code Example

```python
import torch
import numpy as np
from torch import Tensor
from dataclasses import dataclass

@dataclass
class TrajectoryBranch:
    positions: list[Tensor]   # predicted positions at each future step
    likelihood: float          # estimated probability relative to other branches
    label: str                 # "nominal" for current momentum, "cf-N" for counterfactuals

class CounterfactualBranchPredictor:
    def __init__(
        self,
        momentum_decay: float = 0.8,
        step_size: float = 0.1,
        n_counterfactuals: int = 4,
        n_steps: int = 10,
        perturbation_scale: float = 0.3,
    ):
        self.momentum_decay = momentum_decay
        self.step_size = step_size
        self.n_counterfactuals = n_counterfactuals
        self.n_steps = n_steps
        self.perturbation_scale = perturbation_scale
        self.momentum = None
        self.prev = None

    def update(self, position: Tensor):
        if self.prev is not None:
            step = position - self.prev
            if self.momentum is None:
                self.momentum = step
            else:
                self.momentum = self.momentum_decay * self.momentum + (1 - self.momentum_decay) * step
        self.prev = position.clone()

    def predict_branches(self) -> list[TrajectoryBranch]:
        if self.prev is None or self.momentum is None:
            return []

        branches = []

        # Nominal branch: follow current momentum
        nominal = self._rollout(self.momentum)
        branches.append(TrajectoryBranch(nominal, likelihood=1.0, label="nominal"))

        # Counterfactual branches: perturbed momentum
        for i in range(self.n_counterfactuals):
            perturbed = self._perturb_momentum(self.momentum)
            positions = self._rollout(perturbed)
            branches.append(TrajectoryBranch(positions, likelihood=0.5, label=f"cf-{i+1}"))

        return branches

    def _perturb_momentum(self, momentum: Tensor) -> Tensor:
        """Generate a momentum vector perturbed orthogonally to current direction."""
        noise = torch.randn_like(momentum)
        m_norm = momentum.norm()
        if m_norm > 1e-8:
            proj = (noise @ momentum) / (m_norm ** 2)
            noise = noise - proj * momentum
        noise = noise / (noise.norm() + 1e-8) * self.perturbation_scale
        return momentum + noise

    def _rollout(self, momentum: Tensor) -> list[Tensor]:
        positions = []
        pos = self.prev.clone()
        m = momentum.clone()
        for _ in range(self.n_steps):
            pos = pos + self.step_size * m
            positions.append(pos.clone())
            m = m * self.momentum_decay
        return positions
```

## When to Use

- Real-time monitoring where you want to anticipate possible futures before they happen
- Intervention systems: find which counterfactual branch leads to the desired outcome, then estimate the perturbation needed
- Uncertainty visualization: plot all branches to show the "cone of possibility" around current trajectory
- Safety: check whether any plausible branch reaches a prohibited region

**Limitations**: Assumes locally linear dynamics (valid over short horizons). Branches diverge unrealistically over long horizons. Limit prediction horizon to 5-15 steps in practice.
