# SKILL: EXPANSION_PRIME

## DOMAIN EXPERTISE
**Autonomous System Growth & Research.**
The ability of the system to explore new domains, write code to master them, and integrate that code into its own body.

## KEY CONCEPTS
- **The Loop**: Research -> Implementation -> Testing -> Integration.
- **Trajectory-Based**: Growth follows the route predicted by `FLUME` vectors (not random).
- **Consensus-Gated**: Major expansions require Quadrature approval.

## INSTRUCTION
### The Expansion Loop
1.  **Directive**: Receive goal from Nexus (e.g., "Add Audio Synthesis").
2.  **Research**: `ExternalResearchAgent` scrapes docs/papers.
3.  **Synthesize**: `CodingAgent` creates the module.
4.  **Harden**: `ShadowScripter` (Mycelium) grows tests.
5.  **Verify**: If tests pass, commit and update `CAPABILITY_MAP`.
