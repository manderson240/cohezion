# Mode Locking Between Helimagnetism and Ferromagnetism

Nature Physics paper demonstrating microwave emission and mode coupling in a Cu2OSeO3/Pt/NiFe heterostructure.

## Key Findings

- Uses time-resolved resonant elastic X-ray scattering to visualize exact vectorial spin precession modes in real time
- Ferromagnetic NiFe layer dynamically captures excitation modes of the conical order in helimagnet Cu2OSeO3
- Off-resonance NiFe spin precession is phase locked to the helimagnet with a fixed offset
- Presents distinct chiral dynamics between the two magnetic species
