## What Users Get

### Installation Options

**Option 1: PyPI (MCP Server Only)**
```bash
pip install kyutai-mcp-server
kyutai-mcp-server --help
```

**Option 2: Obsidian Plugin**
1. Open Obsidian Settings
2. Navigate to "Community Plugins"
3. Click "Browse"
4. Search for "Kyutai MCP"
5. Click "Install"
6. Enable the plugin

**Option 3: Docker**
```bash
git clone https://github.com/user/kyutai-mcp-server.git
cd kyutai-mcp-server
docker-compose up
```

### Features Available

**MCP Server (7 Tools)**:
- speak_text: Convert text to speech (Pocket TTS)
- transcribe_audio: Convert audio to text
- translate_speech: Real-time speech translation
- list_models: List available models
- get_model_status: Check model health
- set_voice: Configure voice settings
- configure_service: Advanced configuration

**Obsidian Plugin (4 Commands)**:
- Read Note Aloud (Ctrl+Shift+P): TTS for selected text
- Transcribe Audio (Ctrl+Shift+T): STT for audio files
- Clone Voice (Ctrl+Shift+V): Voice cloning setup
- Model Status (Ctrl+Shift+S): Health check

**Plugin Settings (40+ Options)**:
- General: API endpoint, timeouts, logging
- TTS: Voice selection, speed, pitch
- STT: Model selection, language
- Voice: Cloning, samples, settings
- API: Authentication, rate limiting
- Cache: Storage, retention
- Behavior: Auto-play, formatting
- Accessibility: WCAG AA support
- Experimental: Beta features
