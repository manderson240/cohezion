# GraphReactor — Pre-Computed Graph Intelligence

## Problem

Claude needs graph awareness (vault health, dark countries, orphan neurons, etc.)
at the start of every session. Naively, this means 5+ SurrealDB curl calls during
session init, costing ~5,000 tokens and adding latency.

**Better:** A daemon pre-computes the results whenever the vault changes and writes
a single markdown file. Claude reads the file at session start — one file read,
zero db queries, ~500 tokens.

## Key Insight: Not All Tokens Are Created Equal

- 5 SurrealDB runtime queries → ~5,000 tokens (expensive, every session)
- 1 pre-written markdown file → ~500 tokens (cheap, always fresh)
- Daemon runs queries when the user is already editing — zero extra latency

This is **compound engineering**: the reactor fires automatically inside the
existing inotify watch loop. No new process, no new scheduler.

## Architecture

```
inotify event → watch_vault() event loop
                        ↓ (every 60s, if events occurred)
                  GraphReactor.maybe_react()
                        ↓
                  5 SurrealDB queries (parallel conceptually, sequential in code)
                        ↓
                  build markdown string
                        ↓ (only if content changed — SHA-256 hash check)
                  write metabolism/graph-alerts.md
```

## Complete Implementation

```python
import hashlib
import time
from pathlib import Path

REACTOR_THROTTLE_SECS = 60
ALERTS_FILE = Path("metabolism/graph-alerts.md")

class GraphReactor:
    """Pre-computes graph intelligence into vault files for Claude to read."""

    def __init__(self, db):
        self.db = db
        self._last_run = 0.0
        self._last_hash = ""

    def maybe_react(self, changed_country: str = "") -> bool:
        """Run reactor if throttle has elapsed. Returns True if file was written."""
        now = time.time()
        if now - self._last_run < REACTOR_THROTTLE_SECS:
            return False
        self._last_run = now
        return self._run(changed_country)

    def _run(self, changed_country: str = "") -> bool:
        try:
            dark = self._query_dark_countries()
            low = self._query_low_countries()
            orphans = self._query_orphan_neurons()
            resting = self._query_resting_notes()
            hiho = self._query_recent_hiho()
            gaps = self._query_synapse_gaps()
        except Exception as e:
            print(f"GraphReactor query error: {e}", file=sys.stderr)
            return False

        content = self._build_markdown(dark, low, orphans, resting, hiho, gaps)
        content_hash = hashlib.sha256(content.encode()).hexdigest()

        if content_hash == self._last_hash:
            return False  # No change — don't write

        self._last_hash = content_hash
        ALERTS_FILE.parent.mkdir(exist_ok=True)
        ALERTS_FILE.write_text(content, encoding="utf-8")
        return True

    def _build_markdown(self, dark, low, orphans, resting, hiho, gaps) -> str:
        from datetime import date
        today = date.today().isoformat()
        lines = [
            "---",
            "title: Graph Alerts — Live Dashboard",
            f"date: {today}",
            "tags: [metabolism, graph-reactor, auto-generated]",
            "aspect: connective",
            "---",
            "",
            "# Graph Alerts",
            "",
            f"> Auto-generated by `vault_sync.py` GraphReactor on {today}.",
            "> Read by vault-keeper at session start. Do not edit manually.",
            "",
        ]
        # Dark countries
        lines += ["## Dark Countries (health < 0.3)", ""]
        if dark:
            lines += ["| Country | Health | Neurons | Action |",
                      "|---------|--------|---------|--------|"]
            for r in dark:
                lines.append(
                    f"| {r['name']} | {r['health']:.3f} | {r['neuron_count']} "
                    f"| Flesh out notes in `{r['name']}/` |"
                )
        else:
            lines.append("None. All countries above dark threshold.")
        lines.append("")
        # ... (build remaining sections similarly)
        return "\n".join(lines)
```

## Query Patterns

### Dark Countries (health < 0.3)

```python
def _query_dark_countries(self) -> list[dict]:
    results = self.db.query(
        "SELECT name, health, neuron_count FROM country "
        "WHERE health < 0.3 ORDER BY health ASC LIMIT 10;"
    )
    return results or []
```

### Orphan Neurons (high activation, 0 inbound)

```python
def _query_orphan_neurons(self) -> list[dict]:
    results = self.db.query(
        "SELECT path, activation, synapse_out FROM neuron "
        "WHERE synapse_in = 0 AND activation > 0.7 "
        "ORDER BY activation DESC LIMIT 10;"
    )
    return results or []
```

### Synapse Gaps (tag-based co-occurrence without synapses)

Two neurons that share 2+ tags but have no synapse are missed connections:

```python
def _query_synapse_gaps(self) -> list[tuple[str, str]]:
    """Find cortex neuron pairs sharing 2+ tags but no synapse."""
    neurons = self.db.query(
        "SELECT id, path, tags FROM neuron "
        "WHERE cluster_id = 'cortex' AND array::len(tags) > 0 "
        "ORDER BY activation DESC LIMIT 100;"
    )
    if not neurons:
        return []

    # Build tag → neuron index
    tag_to_neurons: dict[str, list] = {}
    for n in neurons:
        for tag in (n.get("tags") or []):
            tag_to_neurons.setdefault(tag, []).append(n)

    # Find pairs sharing 2+ tags
    from itertools import combinations
    pair_shared: dict[tuple, set] = {}
    for tag, ns in tag_to_neurons.items():
        for a, b in combinations(ns, 2):
            key = (min(str(a["id"]), str(b["id"])),
                   max(str(a["id"]), str(b["id"])))
            pair_shared.setdefault(key, set()).add(tag)

    # Filter to pairs with 2+ shared tags
    candidates = [(k, v) for k, v in pair_shared.items() if len(v) >= 2]
    candidates.sort(key=lambda x: -len(x[1]))

    # Check which pairs already have synapses
    gaps = []
    for (id_a, id_b), _ in candidates[:30]:
        exists = self.db.query(
            f"SELECT count() FROM synapse "
            f"WHERE (in = {id_a} AND out = {id_b}) "
            f"OR (in = {id_b} AND out = {id_a}) GROUP ALL;"
        )
        count = exists[0].get("count", 0) if exists else 0
        if count == 0:
            # Resolve to note names for display
            n_a = next((n for n in neurons if str(n["id"]) == id_a), None)
            n_b = next((n for n in neurons if str(n["id"]) == id_b), None)
            if n_a and n_b:
                name_a = Path(n_a["path"]).stem.replace("-", " ").title()
                name_b = Path(n_b["path"]).stem.replace("-", " ").title()
                gaps.append((name_a, name_b))
        if len(gaps) >= 15:
            break

    return gaps
```

## Wiring into inotify watch loop

```python
def watch_vault(db, quiet=False):
    reactor = GraphReactor(db)
    watcher = InotifyWatcher()
    watcher.add_tree(str(VAULT_ROOT), skip_dirs={".git", ".obsidian"})

    initial_sync()

    # Force first reactor run immediately after sync
    reactor._last_run = 0
    if reactor.maybe_react():
        if not quiet:
            print("Graph reactor: initial alerts written", file=sys.stderr)

    pending = {}
    while True:
        events = watcher.read_events(timeout_ms=200)
        # ... process events into pending dict ...

        # Flush debounced events
        now = time.monotonic()
        for path, (event_type, ts) in list(pending.items()):
            if now - ts >= 0.5:
                del pending[path]
                handle_event(event_type, path, db)

        # Reactor fires after any events — throttled to 60s
        if events:
            if reactor.maybe_react():
                if not quiet:
                    print("Graph reactor: alerts updated", file=sys.stderr)
```

## Throttle Tuning

| Activity Level | Recommended Throttle |
|---------------|---------------------|
| Active editing (many changes/min) | 60s (default) |
| Occasional changes | 30s |
| Bulk imports | 120s (avoid thrashing) |
| Never write unnecessarily | Use content-hash dedup (always) |

## Pitfalls

| Pitfall | Fix |
|---------|-----|
| Writes file on every event | Add content-hash dedup (SHA-256) |
| Queries fail silently | Wrap `_run()` in try/except, return False |
| Reactor blocks event loop | All queries are synchronous but fast (<200ms total) |
| First run misses initial state | Force `_last_run = 0` after initial sync |
| SurrealDB field-projection HTTP 400 | Use `SELECT *` and filter in Python (see surrealdb-debug skill) |
