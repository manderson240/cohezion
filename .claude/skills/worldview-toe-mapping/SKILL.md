# Worldview-TOE Mapping

## The Core Distinction: Structural Identity vs. Metaphor

Every indigenous knowledge system has been compared to Western physics via poetic metaphor. This skill is different — it finds **mathematical and structural identity**:

- Ifá (256 Odù) IS an 8-bit oracle (2⁸) — not "like" information theory
- Whakapapa IS a directed acyclic graph — not "like" a family tree or network
- The Great Law of Peace IS a Byzantine fault-tolerant consensus protocol
- Sand paintings ARE quantum measurement diagrams (state prep → interference → collapse → destruction)

If the correspondence requires "it's sort of like..." — reject it. Find the one that says "this IS that."

## Priority: Indigenous Authors First

For every tradition, find indigenous scholars as the primary sources:
- Lakota: Vine Deloria Jr., Joseph Marshall III
- Māori: Hirini Moko Mead, Linda Tuhiwai Smith
- Yoruba: Wande Abimbola (Awise Agbaye), Kólá Abímbólá
- Haudenosaunee: John Mohawk (Seneca), Oren Lyons (Onondaga)

Secondary sources (Western academics with indigenous community collaboration) only when no indigenous scholar has written on the topic.
