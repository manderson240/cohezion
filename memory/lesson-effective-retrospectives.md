# Lesson: Effective Retrospectives: Structured Session Reviews Extract Maximum Learnings

## Context

Unstructured session retrospectives capture little actionable learning. Structured retrospectives using consistent frameworks extract specific, reusable patterns from session experience.

## Core Learning

**Use structured retrospective format: What worked, What failed, What was surprising, What is the reusable pattern.**

### Structure
```markdown
# Session Retrospective

## What Worked
- [Specific technique that succeeded and why]

## What Failed
- [What broke, error message, root cause discovered]

## What Was Surprising
- [Assumption violated, unexpected behavior, counterintuitive finding]

## Reusable Patterns Extracted
- [Generalizable rule for future sessions]

## Token Efficiency
- [Cost of what worked vs what failed]

## Next Session Priorities
- [Ordered list of highest-value next actions]
```

## Recommendations

### Do
- Complete retrospective at session end before context is lost
- Focus on extractable patterns (general rules), not specific facts
- Save patterns immediately to vault

### Don't
- Write retrospectives without the structured format
- Focus only on what worked (failures contain more learning)
