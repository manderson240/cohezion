## 2. arXiv: Agent Governance & Safety

### Layered Governance Architecture (LGA) -- arXiv:2603.07191 (March 2026)
- **What:** Four-layer framework: L1 execution sandboxing, L2 intent verification, L3 zero-trust inter-agent authorization, L4 immutable audit logging. Tested on 1,081 tool-call samples covering prompt injection, RAG poisoning, malicious skill plugins. L2 intercepts 93-98.5% of malicious tool calls.
- **Cohezion connection:** **Directly actionable.** Maps cleanly to Cohezion's Constitution/Charter enforcement. L1 = Cohezion's execution sandboxing, L2 = RequestAlignmentAnalyzer, L3 = inter-agent authorization in TeamOrchestrator, L4 = JourneyTracker audit trail. The bilingual benchmark methodology could be adapted for testing Cohezion's own governance.
- **Source:** [arXiv:2603.07191](https://arxiv.org/abs/2603.07191)

### AGENTSAFE -- arXiv:2512.03180
- **What:** Unified governance framework with semantic telemetry, dynamic authorization, anomaly detection, interruptibility, and cryptographic tracing. Operationalizes the AI Risk Repository into design/runtime/audit controls.
- **Cohezion connection:** The semantic telemetry and anomaly detection patterns could enhance Cohezion's DegradationDetector and GlobalMetricsAggregator.
- **Source:** [arXiv:2512.03180](https://arxiv.org/abs/2512.03180)

### Autonomy Certificates -- arXiv:2506.12469
- **What:** Digital documents prescribing maximum autonomy levels for agents, analogous to safety cases. Issued by third-party governing bodies to communicate behavioral characteristics.
- **Cohezion connection:** Could be implemented as part of Cohezion's skill metadata. Each PRIME skill could carry an autonomy certificate specifying its operational boundaries.
- **Source:** [arXiv:2506.12469](https://arxiv.org/html/2506.12469v1)

### Orchestration of Multi-Agent Systems -- arXiv:2601.13671 (Jan 2026)

## 4. arXiv: KV Cache Compression (TurboQuant-Related)

### TurboQuant at ICLR 2026
- **What:** Combines PolarQuant + QJL into a deployment-ready pipeline. Error approaching Shannon information-theoretic lower bound. 4-bit sweet spot where quality is nearly indistinguishable from FP16 on models 3B+.
- **Cohezion connection:** Directly relevant to Cohezion's inference optimization. At 4-bit KV cache, local Ollama models (deepseek-r1:70b) could handle much longer contexts within the 128GB LPDDR5X budget.
- **Source:** [TurboQuant Analysis](https://www.revolutioninai.com/2026/03/%20google-turboquant-kv-cache-compression-polarquant-qjl-explained-2026.html)

### IsoQuant -- arXiv:2603.28430 (March 30, 2026)
- **What:** SO(4) isoclinic rotations using quaternion algebra for KV cache compression. 4.5-4.7x mean kernel speedups over RotorQuant with comparable reconstruction error. Peak speedups above 6x.
- **Cohezion connection:** The quaternion-based rotation framework has an elegant mathematical connection to Cohezion's SPIN coherence model (rotation + precession). Could potentially unify the KV cache compression math with FLUME's latent space representation.
- **Source:** [arXiv:2603.28430](https://arxiv.org/abs/2603.28430)

### KVSculpt -- arXiv:2603.27819 (March 29, 2026)
- **What:** Optimizes KV pairs in continuous embedding space via L-BFGS (keys) and least-squares (values). 3.5-4.1x KL divergence reduction vs Select+Fit.
- **Cohezion connection:** The continuous optimization approach could be applied to Cohezion's SemanticCache L2 layer for better compressed key representations.
- **Source:** [arXiv:2603.27819](https://arxiv.org/abs/2603.27819)

### VQKV -- Vector Quantization for KV Cache
- **What:** Training-free vector quantization achieving 82.8% compression while retaining 98.6% baseline performance and enabling 4.3x longer generation.
- **Cohezion connection:** Training-free is key -- could be applied to Cohezion's local Ollama models without retraining.
- **Source:** [VQKV Paper](https://arxiv.org/html/2603.16435)

## 5. arXiv: VAE/Latent Space for Agent Reasoning

### Reasoning Palette (Dec 2025)
- **What:** VAE-learned latent space of reasoning strategies. Shifts exploration from token-level randomness to strategy-level diversity by sampling from a latent space.
- **Cohezion connection:** **Core alignment with FLUME VAE.** Reasoning Palette's concept of encoding distinct reasoning contexts as latent variables mirrors FLUME's 256D latent space for agent state representation.
- **Source:** [Reasoning Palette](https://arxiv.org/html/2512.17206)

### DAAO: Difficulty-Aware Agentic Orchestration (ACM Web Conf 2026)
- **What:** VAE for difficulty estimation + modular operator allocator + cost/performance-aware LLM router. Self-adjusting policy updates difficulty estimates based on workflow success.
- **Cohezion connection:** **Directly integrable.** The VAE-for-difficulty-estimation pattern could enhance Cohezion's TaskTypeRouter with learned task complexity scoring rather than heuristic classification.
- **Source:** [DAAO Paper](https://arxiv.org/html/2509.11079)

### LaDiR: Latent Diffusion for Reasoning (Feb 2026)
- **What:** VAE encodes reasoning steps into "blocks of thought tokens" -- compact but expressive. Latent diffusion then iteratively refines these representations.
- **Cohezion connection:** The "blocks of thought tokens" concept could extend FLUME VAE's latent space to encode not just agent state but reasoning trajectories.
- **Source:** [LaDiR Paper](https://arxiv.org/html/2510.04573)
