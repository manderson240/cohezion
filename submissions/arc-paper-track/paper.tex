\begin{abstract}
We present a deterministic solver for the Abstraction and Reasoning Corpus (ARC-AGI-2) that encodes each grid into a 256-dimensional FLUME-compatible latent vector and extracts verifiable transformation rules through compound engineering consensus across 6 complementary pattern-matching strategies. The solver achieves structural coherence scoring via the HIHO (Half-In-Half-Out) geometric framework, enforcing a minimum coherence threshold of 0.5 before rule application. A SHA-256 provenance manifest accompanies each prediction, enabling full reproducibility and auditability. We report preliminary evaluation methodology and discuss integration with physical substrates — specifically the 12D manifold embedding approach that grounds abstract ARC transformations in geometric state spaces.
\end{abstract}

\section{Introduction}

ARC-AGI-2 requires AI systems to perform novel reasoning across visual abstraction tasks. Unlike standard machine learning benchmarks, ARC tasks exhibit:
\begin{itemize}
\item Few-shot learning (typically 2-5 training examples)
\item Compositional rule structure (multiple primitives combined)
\item Zero transfer from training — each task is conceptually novel
\end{itemize}

Our approach treats ARC grids not as images but as symbolic tensors embedded in a 256-dimensional latent manifold. This manifold, computed by a FLUME (Fluid Latent Understanding through Manifold Encoding) encoder, preserves structural relationships between grid patterns while enabling geometric operations unavailable in pixel space.

\section{Architecture}

\subsection{Compound Rule Consensus}

The solver employs 6 complementary pattern-extraction strategies:

\begin{enumerate}
\item \textbf{Color Constant} — Same-color transformation across training examples
\item \textbf{Object Detection} — Connected-component analysis with geometric primitives
\item \textbf{Grid Symmetry} — Mirror, rotation, and translational symmetry detection
\item \textbf{Scale Mapping} — Upsample/downsample relationships
\item \textbf{Color Map} — Palette permutation and recoloring
\item \textbf{Geometric Primitive DSL} — 18 core ops + parametric variants
\end{enumerate}

Each strategy votes independently. Rules only proceed when $\geq 2$ strategies agree (consensus threshold).

\subsection{HIHO Coherence Gate}

Before applying any predicted transformation, we compute coherence:
\[ C(\vec{z}) = 1 - 2 \cdot \mathbb{E}[|z_i - 0.5|] \]
where $\vec{z}$ is the 256D latent. The task is rejected if $C < 0.5$ (Half-In-Half-Out stability threshold).

\subsection{Deterministic Execution}

All transformation rules are expressed as deterministic Python functions with no randomness. Each execution produces:
\begin{itemize}
\item SHA-256 hash of the rule signature
\item Timestamp
\item Confidence score derived from consensus depth
\end{itemize}

\section{Methodology}

\begin{algorithm}[H]
\caption{ARC Solve Step}
\begin{algorithmic}[1]
\State Load test challenge grid $G_{test}$
\State Encode: $\vec{z} \leftarrow \text{FLUME}(G_{test})$
\State Compute coherence: $c \leftarrow C(\vec{z})$
\If {$c < 0.5$}
    \State \Return \text{fallback\_dsl}$(G_{test})$
\EndIf
\State Extract rules $\{r_1, \dots, r_n\}$ via 6 strategies
\State Filter: $\mathcal{R} \leftarrow \{r_i : \text{consensus}(r_i) \geq 2\}$
\If {$|\mathcal{R}| = 0$}
    \State \Return \text{fallback\_dsl}$(G_{test})$
\EndIf
\State Apply top rule: $G_{pred} \leftarrow r_{top}(G_{test})$
\State \Return $G_{pred}$
\End{algorithmic}
\end{algorithm}

\section{Safety and Verification}

### Alignment Gate
Before any destructive action on the evaluation set, the system checks:
1. Structural invariant: output dimensions match test input structure
2. Color range: all integers in $[0, 9]$
3. Grid validity: rectangular array

### Provenance
Every prediction includes:
- Rule hash (SHA-256 of AST)
- Strategy provenance (which of the 6 strategies proposed it)
- Latent vector (256D, for post-hoc similarity analysis)
- Coherence score
