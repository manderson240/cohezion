# Implementation Plan - Cohezion Phase 4: Nexus Expansion

## Goal Description
Expand the Cohezion platform's capabilities into **Multi-Node Scaling**, **Real-time 12D Visualization**, and **Display Stability**. This phase activates the **Quadrature Nexus** by distributing expert nodes across specific hardware resources and visualizing the **FLUME** state vector in real-time.

## User Review Required
> [!IMPORTANT]
> **GPU Affinity Strategy**: This plan assumes `GPU0` (RX 7700S) is the primary compute node and `GPU1` (Integrated/Other) is secondary/display. Confirm hardware topology if different.

> [!WARNING]
> **Rust Migration**: Moving `FlumeEncoder` to Rust is a significant architectural shift. This plan includes *planning* for it, but full execution might require a dedicated sprint.

## Proposed Changes

### 1. Multi-Node Scaling (Infrastructure)

#### [NEW] `src/cohezion/infrastructure/gpu_affinity.py`
- **Purpose**: Map specific Expert Nodes (Architect, Engineer, etc.) to specific GPUs.
- **Specs**:
  - `GpuAffinityManager`: Singleton that detects available GPUs (AMD ROCm/Vulkan).
  - `assign_affinity(node_type: str) -> dict`: Returns env vars (e.g., `HIP_VISIBLE_DEVICES`) for subprocesses.
  - Configuration: `config/gpu_topology.yaml` (autogenerated or manual).

#### [MODIFY] `src/cohezion/reliability/monitor.py`
- **Purpose**: Enhance throttling logic.
- **Specs**:
  - `check_desperation_mode()`: Existing logic.
  - `calculate_swarm_throttle()`: New method. If CPU > 90%, introduce `sleep(exponential_backoff)` in `ControllerAgent`.

### 2. Web UI & 12D Visualization

#### [MODIFY] `apps/webapp/src/hooks/useOuroboros.ts`
- **Purpose**: Consume real-time 12D state pulse.
- **Specs**:
  - Connect to WebSocket `/ws/pulse` (to be exposed by `start_ouroboros.py`).
  - Update React state with `PulseData` (12D vector + metadata).

#### [NEW] `apps/webapp/src/components/ConnectoidViz.tsx`
- **Purpose**: WebGL visualization of the Neural Loop.
- **Specs**:
  - Use `react-three-fiber`.
  - Render dynamic splines based on `PulseData.coherence` and `PulseData.entropy`.

#### [NEW] `apps/webapp/src/components/ManifoldBackdrop.tsx`
- **Purpose**: Ambient background reflecting "Dark Matter Sheets".
- **Specs**:
