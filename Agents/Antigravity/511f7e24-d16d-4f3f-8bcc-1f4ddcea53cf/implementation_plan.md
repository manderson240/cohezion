# Red/Blue Swarm Modularization & Cleanup Plan

This plan outlines the deployment of specialized swarms to modularize the Cohezion codebase into a series of services, remove technical debt, and ensure system stability through adversarial testing.

## User Review Required

> [!IMPORTANT]
> This plan involves moving files and refactoring core package structures. This may cause temporary build breaks in non-verified branches.
> We will use **Phi-3 Mini** for rapid verification swarms and **Qwen3-Coder** for the final refactoring to minimize VRAM pressure.

## Proposed Changes

### 1. Cleanup Swarm (Ouroboros Reflex)
**Goal**: Locate and remove unused methods and redundant code blocks (e.g., `quantize_q4_k`).

- **Agents**: `ReflexPrunerAgent` (derived from `OuroborosRecorder` reflex logic).
- **Inspiration**: `cohezion.system.ouroboros_recorder._reflex_cycle`.

### 2. Service Modularization Swarm
**Goal**: Divide the monolithic `src/cohezion/` package into a series of domain-driven services:
- `cohezion-agents`: Orchestration & Swarm logic.
- `cohezion-universe`: 12D Manifold & Trajectory physics.
- `cohezion-core`: Reliability, Routing, and Persistence foundations.
- `cohezion-healing`: Immune system & Autonomic Stabilizers.

**Agents**:
- #### [NEW] [ModularizationScout](file:///home/mike-anderson/dev/cohezion/src/cohezion/swarm/agents/modularization_scout.py)
  Uses `DependencyAnalyzer` to map cross-references and identify circular dependencies.
- #### [NEW] [ServiceArchitect](file:///home/mike-anderson/dev/cohezion/src/cohezion/swarm/agents/service_architect.py)
  Proposes specific file moves and module boundaries.
- #### [NEW] [RefactorWorker](file:///home/mike-anderson/dev/cohezion/src/cohezion/swarm/agents/refactor_worker.py)
  Executes `mv` operations and updates `import` statements across the repo.

### 3. Red Team vs Blue Team Swarm (HIHO 0.5)
**Goal**: Validate the new architecture via adversarial stress testing.

- **Red Team (Adversary)**:
  - Deploys `DisruptionSwarm` to inject faults and check for cascading failures in the service layer.
  - Follows [ADVERSARIAL_TESTING_PRIME](file:///home/mike-anderson/dev/cohezion/src/cohezion/skills/ADVERSARIAL_TESTING_PRIME.md).
- **Blue Team (Guardian)**:
  - Deploys `StabilizationSwarm` to monitor coherence via Ouroboros and trigger `AutoHealer`.
  - Follows [HIHO_STABILITY_PRIME](file:///home/mike-anderson/dev/cohezion/src/cohezion/skills/HIHO_STABILITY_PRIME.md).

1. **Cleanup Validation**: Run `pytest` to ensure no functional code was removed by the Pruner.

3. **Red Team Simulation**: Run `uv run scripts/drivers/start_ouroboros.py` and verify it survives a 10-minute disruption cycle.

### Manual Verification
- Review the `modularization_report.md` generated by the `ServiceArchitect`.
- Verify the `RewardSystem` successfully awards XP to agents whose refactors are merged.
