# Compound Engineering Pattern

The meta-pattern for how Cohezion compounds knowledge across agent sessions: execute, observe, extract, index, inject.

## Cycle
1. Agent session executes
2. Observations saved to memory
3. Lessons/decisions written to vault
4. 3D graph updated
5. Next session loads context
