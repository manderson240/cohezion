# Lesson 22: GITIGNORE ORDERING

## Original Text
**GITIGNORE ORDERING**: `.gitignore` rules are order-dependent. A later `!src/**/*.json` re-include will override earlier specific ignores. Place specific file ignores AFTER blanket re-includes.
