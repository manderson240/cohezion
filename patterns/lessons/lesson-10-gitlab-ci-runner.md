# Lesson 10: GITLAB CI RUNNER

## Original Text
**GITLAB CI RUNNER**: Use `clone_url = "http://localhost:8929"` in runner config to avoid `gitlab.local` DNS failure. Install runner to `~/.local/bin/` if sudo unavailable. Shell executor needs PATH set to find `uv`.
