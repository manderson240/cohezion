# Lesson 27: HOOK FILE REVERT

## Original Text
**HOOK FILE REVERT**: PostToolUse ruff hook can revert untracked files and edits. After writing new files, IMMEDIATELY `git add` them before hook triggers. Or: write + add in same Bash call. Alternative: use `.venv/bin/ruff` directly if `uv run ruff` hangs.
